GitHub PagesをGoogle Search Consoleへ登録する方法

GitHub Pagesで公開したサイトをGoogle Search Consoleへ登録し、所有権を確認する流れを解説します。

結論

GitHub PagesをGoogle Search Consoleへ登録する場合は、実際に公開されているGitHub PagesのURLを確認し、Search Consoleでプロパティを追加して所有権を確認します。

GitHub Pagesでは https://ユーザー名.github.io/ のようなURLだけでなく、プロジェクトサイトではパスが付く場合があります。登録前にブラウザで開いている正式な公開URLを確認してください。

1. 公開URLを確認する

GitHub Pagesのサイトをブラウザで開き、アドレス欄のURLを確認します。

独自ドメインを設定している場合は、実際に検索対象として管理したいドメイン・URLを基準にします。

2. Search Consoleでプロパティを追加する

Search Consoleへログインし、プロパティ追加を開きます。

GitHub Pagesの特定URLを登録する場合は、URLプレフィックスを利用すると、HTMLファイルなど利用可能な確認方法を選べる場合があります。

入力するURLは https:// やパスを含め、管理対象と一致させます。

3. 所有権を確認する

画面に表示された所有権確認方法から、自分のGitHub Pagesで利用できるものを選びます。

HTMLファイル方式を使う場合は、Search Consoleから取得した確認用ファイルをGitHub Pagesの公開領域へ配置し、指定URLで開ける状態にします。

4. 確認成功後も認証情報を残す

HTML確認ファイルなど、所有権確認に使った情報は確認成功後も削除しないようにします。

削除すると、後の再確認で所有権を維持できなくなる可能性があります。

5. サイトマップやURL検査を確認する

登録後は、サイトマップがある場合はSearch Consoleから送信できます。

特定ページの状態を調べたい場合はURL検査を使い、GoogleがそのURLを認識しているか確認します。

GitHubのリポジトリURLを登録しない

Search Consoleで管理したいのは、通常はGitHubのリポジトリ画面ではなく、GitHub Pagesとして公開されているWebサイトです。

github.com/... の編集・管理画面と、github.io/... などの公開サイトURLを混同しないようにします。

まとめ

GitHub PagesをSearch Consoleへ登録するときは、最初に公開サイトの正確なURLを確認します。そのURLをプロパティとして追加し、HTMLファイルなど利用可能な方法で所有権を確認してください。
