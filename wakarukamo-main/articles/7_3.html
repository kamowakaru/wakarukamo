CSSとは？HTMLとの違いと役割を初心者向けに解説

CSSは、HTMLで作ったWebページの色・文字サイズ・余白・配置などの見た目を指定するための言語です。HTMLがページの構造、CSSがデザインを担当すると考えると分かりやすいです。

結論

CSS（Cascading Style Sheets）は、Webページの見た目を指定するための言語です。HTMLが「見出し」「本文」「リンク」といった構造を作り、CSSがそれらをどう見せるかを決めます。

HTMLとCSSの違い

たとえばHTMLに次の見出しがあるとします。

<h1>ワカルカモ</h1>

CSSで次のように指定すると、文字の色やサイズを変更できます。

h1 {
  color: navy;
  font-size: 32px;
}

つまり、HTMLは内容の意味、CSSは見た目という役割分担です。HTMLの基本はHTMLとは？で解説しています。

CSSでできること

CSSでは、たとえば次のような調整ができます。

  • 文字色や背景色を変える
  • 文字サイズや太さを変える
  • 要素の間に余白を付ける
  • 横並び・縦並びを指定する
  • 画面幅に応じてスマホ向け表示へ変える
  • ボタンやカードの枠・角丸・影を付ける

Webサイト全体で同じCSSファイルを読み込めば、共通デザインを一括管理できます。記事が100ページあっても、共通CSSを直すだけで全ページの見た目を変更できる構成も作れます。

CSSはどこに書く？

小さなテストならHTML内にも書けますが、サイトでは style.css のような別ファイルにまとめる方法が一般的です。

<link rel="stylesheet" href="style.css">

この1行をHTMLの <head> 内に置くと、外部CSSファイルを読み込めます。

CSSだけではページは作れない

CSSは「何を表示するか」を作るものではありません。基本はHTMLで文章・画像・リンクなどを用意し、それらにCSSでデザインを付けます。

まず小さなHTMLを作ってから、背景色、文字サイズ、余白の順にCSSを追加すると変化が分かりやすいです。完成したファイルを公開する方法は作ったWebサイトをインターネットに公開する方法へ進んでください。
