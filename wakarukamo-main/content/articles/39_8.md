## 結論

ブログを公開したら、**GA4でサイト内のアクセス、Search ConsoleでGoogle検索上の状態**を確認できるようにします。

設定コードを入れただけで終わらせず、自分でサイトを開き、データが届いていることまで確認します。

## 1. GA4のプロパティとデータストリームを作る

Google Analyticsでプロパティを作成し、Webデータストリームへ公開URLを登録します。

発行された`G-`から始まる測定IDを控えます。別サイトの測定IDを入れないよう、サイト名とURLを確認します。

## 2. 測定タグをサイトへ入れる

サイトの全ページで使うHTMLテンプレートの`head`内へ測定タグを入れます。

記事HTMLを自動生成している場合は、生成済みの全HTMLを直接修正せず、共通テンプレートや設定ファイルへ測定IDを入れて再生成します。

## 3. リアルタイムで自分のアクセスを確認する

公開サイトを別タブで開き、GA4のリアルタイム画面を確認します。

表示されない場合は次を見ます。

- 公開ページのHTMLに測定タグが入っているか
- 測定IDが一致しているか
- 広告ブロック機能で止められていないか
- ローカルファイルではなく公開URLを開いているか
- 更新後のHTMLが公開されているか

## 4. Search Consoleへサイトを登録する

Search Consoleでプロパティを追加します。GitHub Pagesのように特定URL配下で運営する場合は、URLプレフィックスで登録する方法があります。

所有権の確認方法としてHTMLファイルを使う場合は、指定された確認ファイルを内容や名前を変えずに公開先へ置きます。

## 5. URL検査でトップページを確認する

Search ConsoleのURL検査へトップページのURLを入力します。

公開直後は「Googleに登録されていません」と表示されても不自然ではありません。ページが一般公開され、Googleがアクセスできる状態かを確認します。

## 6. GA4とSearch Consoleの役割を混ぜない

| 確認したいこと | 主に使うもの |
|---|---|
| 今サイトを見ている人がいるか | GA4 |
| よく読まれるページ | GA4 |
| どんな検索語で表示されたか | Search Console |
| Googleに登録されているか | Search Console |
| 検索結果でのクリック数 | Search Console |

公開直後はデータが少ないため、数字がゼロでも設定ミスとは限りません。

## 今回の完成チェック

- GA4の測定IDを正しいサイトへ設定した
- リアルタイムで自分のアクセスを確認した
- Search Consoleの所有権確認が完了した
- URL検査でトップページを確認した
- GA4とSearch Consoleの用途を分けて見られる
