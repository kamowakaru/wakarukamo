## 結論

GASでスプレッドシートのデータを自動処理する基本は、**対象範囲をまとめて配列として取得し、JavaScript側で処理してから必要な結果をまとめて書き戻す**方法です。

大量のセルを1つずつ`getValue()`・`setValue()`するより、シートとの読み書き回数を減らす方が処理を組み立てやすくなります。

## 対象のスプレッドシートを決める

スプレッドシートに紐づいたスクリプトなら、アクティブなスプレッドシートからシートを取得できます。

```javascript
function processData() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getSheetByName('データ');

  if (!sheet) {
    throw new Error('シート「データ」が見つかりません。');
  }
}
```

シート名を固定する場合は、名前変更時にエラーになることを想定します。

## データをまとめて取得する

たとえばA2:Cのデータを扱う場合、最終行を確認して範囲を取得します。

```javascript
const lastRow = sheet.getLastRow();

if (lastRow < 2) {
  return;
}

const values = sheet.getRange(2, 1, lastRow - 1, 3).getValues();
```

`getValues()`の結果は2次元配列です。

## 配列を処理する

たとえばC列の数値を2倍した結果を作るなら、次のように処理できます。

```javascript
const results = values.map(row => {
  const value = row[2];
  return [typeof value === 'number' ? value * 2 : ''];
});
```

シート上の列番号とJavaScript配列の添字は数え方が違うため注意します。

A列はシートでは1列目ですが、取得した配列では`row[0]`です。

## 結果をまとめて書き込む

D列へ結果を書き込む例です。

```javascript
sheet
  .getRange(2, 4, results.length, 1)
  .setValues(results);
```

`setValues()`へ渡す配列の行数・列数は、書き込み先の範囲サイズと一致させます。

## 全体の例

```javascript
function processData() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getSheetByName('データ');

  if (!sheet) {
    throw new Error('シート「データ」が見つかりません。');
  }

  const lastRow = sheet.getLastRow();

  if (lastRow < 2) {
    return;
  }

  const values = sheet.getRange(2, 1, lastRow - 1, 3).getValues();

  const results = values.map(row => {
    const value = row[2];
    return [typeof value === 'number' ? value * 2 : ''];
  });

  sheet.getRange(2, 4, results.length, 1).setValues(results);
}
```

実際に使うときは、シート名、列、計算内容を自分の表へ合わせます。

## ヘッダー行を除外する

1行目が見出しなら、データ範囲を2行目から取得します。

ヘッダーまで処理対象に含めると、文字列を数値として扱うなどのエラーにつながる場合があります。

## 空行や不正な値を考える

実際の表には空欄や文字列が混ざることがあります。

「必ず数値が入る」と決めつけず、値の種類や空欄を確認して処理します。

## 自動実行する前にテストする

コードが完成しても、すぐトリガーへ登録せず、テスト用のデータで手動実行します。

特に`setValues()`は実データを書き換えるため、対象列と開始行を確認してください。

## 定期処理へつなげる

手動実行で問題がなければ、時間主導型トリガーなどを設定して自動実行できます。

同じデータを何度も処理して困る場合は、処理済みフラグや最終処理位置を持たせる設計を追加します。

## まとめ

GASでスプレッドシートを自動処理するときは、`getValues()`でまとめて読み込み、配列を処理し、`setValues()`でまとめて書き戻す流れが基本です。空欄やシート名の変更なども想定し、手動テスト後に自動実行へ進めてください。
