## 結論

GASで複数のスプレッドシートを照合するときは、**それぞれの表をまとめて配列へ読み込み、共通のIDなどをキーにして比較**します。

行ごとに別のスプレッドシートへアクセスすると処理回数が増えるため、最初に必要なデータを取得してからJavaScript側で照合する構成が基本です。

## 照合キーを決める

たとえば2つの表に次の列があるとします。

```text
管理表A
ID | 名前 | 状態

管理表B
ID | メール
```

この場合は`ID`を照合キーにします。

名前は表記ゆれや同姓同名があるため、一意に管理できるIDがあるならそちらを使います。

## 別のスプレッドシートを開く

スプレッドシートIDが分かっている場合は、`openById()`で対象を取得できます。

```javascript
const ssA = SpreadsheetApp.openById('SPREADSHEET_ID_A');
const ssB = SpreadsheetApp.openById('SPREADSHEET_ID_B');

const sheetA = ssA.getSheetByName('データ');
const sheetB = ssB.getSheetByName('データ');
```

IDやシート名は実際の環境へ合わせます。

## データをまとめて取得する

```javascript
const valuesA = sheetA.getDataRange().getValues();
const valuesB = sheetB.getDataRange().getValues();
```

1行目がヘッダーなら、処理時に除外します。

## Mapへ変換する

表BのIDをキーにして、メールアドレスを取り出せるようにします。

```javascript
const mapB = new Map();

valuesB.slice(1).forEach(row => {
  const id = String(row[0]).trim();
  const email = row[1];

  if (id) {
    mapB.set(id, email);
  }
});
```

これでIDから対応データを探せます。

## 表Aと照合する

```javascript
const results = valuesA.slice(1).map(row => {
  const id = String(row[0]).trim();
  const email = mapB.get(id) || '';
  return [email];
});
```

結果を表Aの新しい列へまとめて書き込みます。

```javascript
if (results.length > 0) {
  sheetA.getRange(2, 4, results.length, 1).setValues(results);
}
```

## キーの型をそろえる

片方では数値`123`、もう片方では文字列`"123"`になっていると、比較方法によって一致しない場合があります。

照合前に`String()`や`trim()`などで形式をそろえます。

ただし、先頭ゼロが意味を持つIDでは、スプレッドシート側で値がどのように保存されているかも確認してください。

## 重複キーを確認する

同じIDが複数行に存在すると、単純な`Map`では後の値で上書きされます。

IDが本当に一意か確認し、重複が正常なデータなら配列として複数件を保持する設計へ変えます。

## 大量データではアクセス回数を減らす

GASでは、セルを1件ずつ読みながら別シートを検索するより、必要な範囲をまとめて取得し、メモリ上で照合する方が効率的です。

結果も`setValues()`でまとめて書き戻します。

## まとめ

複数スプレッドシートの照合では、共通キーを決め、両方のデータをまとめて取得し、`Map`などで対応付けます。型の違い、空欄、重複キーを確認し、実データを書き換える前に少量データでテストしてください。
