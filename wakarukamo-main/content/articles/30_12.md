## 結論

複数のHTMLページのデザインを一括変更するには、**各ページから同じ外部CSSファイルを読み込む構成**にします。

100ページの見出し色を変える場合でも、共通CSSで指定していれば、基本的にはCSS側のルールを修正するだけで済みます。

## 共通CSSを読み込む

各HTMLの`head`から同じCSSを読み込みます。

```html
<link rel="stylesheet" href="/css/style.css">
```

`style.css`に共通デザインを書きます。

```css
body {
  font-family: sans-serif;
}

h2 {
  margin-top: 2rem;
}
```

これらのHTMLが同じCSSを参照していれば、CSSの変更が各ページへ適用されます。

## HTMLごとに同じstyleを書かない

各HTMLへ次のような`style`をコピーすると、後で変更するときに全ファイルを修正することになります。

```html
<style>
  h2 {
    margin-top: 2rem;
  }
</style>
```

ページ固有の事情がなければ、共通ルールは外部CSSへまとめます。

## classで部品を共通化する

注意書きなど、特定の部品へ同じデザインを使う場合はclassを付けます。

```html
<div class="note">
  注意事項
</div>
```

CSS側で共通デザインを指定します。

```css
.note {
  padding: 1rem;
  border: 1px solid;
}
```

後から`.note`のデザインを変更すれば、そのclassを使うページへまとめて反映できます。

## ページ固有のCSSは必要な分だけ追加する

特定ページだけレイアウトが違う場合は、共通CSSをコピーして別ファイルを大量に作るより、共通ルールを土台に必要な差分だけ追加する方が管理しやすくなります。

## HTML構造も共通ならテンプレート化する

CSSは見た目を共通化できますが、全ページのヘッダーへ同じ要素を追加するような「HTML構造の変更」はCSSだけでは対応できません。

その場合はHTMLテンプレートを共通化し、各ページを自動生成する構成が向いています。

## 変更が反映されないとき

CSSを修正したのに見た目が変わらない場合は、次を確認します。

- HTMLが正しいCSSファイルを読み込んでいる
- CSSのパスが正しい
- 別のCSSルールに上書きされていない
- 公開先へ最新ファイルが反映されている
- ブラウザや配信環境のキャッシュが影響していないか

開発者ツールで実際に適用されているCSSを確認すると切り分けやすくなります。

## まとめ

複数HTMLのデザインは、外部CSSを共通化することで一括変更できます。見た目はCSS、ページ構造はHTMLテンプレートへ分けると、ページ数が増えても修正しやすい構成になります。
