## 結論

ショートカットキーは、キーボードの複数のキーを同時に押して操作する機能です。まずは **Ctrl＋C**（コピー）、**Ctrl＋V**（貼り付け）、**Ctrl＋Z**（元に戻す）を覚えると、文章やファイルの操作で役立ちます。

ここで紹介する基本操作の多くはWindows 11とWindows 10の両方で使えます。ただし、アプリ独自のショートカットはアプリによって動作が異なります。

## キーの読み方

「＋」はキーを同時に押す意味です。たとえば **Ctrl＋C** は、Ctrlキーを押しながらCキーを押します。**Windowsキー**は、キーボードにあるWindowsロゴのキーです。

## まず覚えたい基本操作

| ショートカット | できること |
| --- | --- |
| Ctrl＋C | 選択した文字やファイルをコピーする |
| Ctrl＋X | 選択した文字やファイルを切り取る |
| Ctrl＋V | コピーまたは切り取った内容を貼り付ける |
| Ctrl＋Z | 直前の操作を元に戻す |
| Ctrl＋A | 表示中の場所の内容をすべて選択する |
| Ctrl＋S | 作業中のファイルを保存する |
| Ctrl＋F | 文書やページ内の文字を検索する |
| Alt＋F4 | 開いているウィンドウやアプリを閉じる |

これらは多くのアプリで使えますが、アプリや作業内容によって使えない場合があります。保存前に確認画面が出たら、内容を確認してから選択してください。

## Windowsの操作に便利なキー

| ショートカット | できること |
| --- | --- |
| Windowsキー＋E | エクスプローラーを開く |
| Windowsキー＋D | デスクトップを表示する。もう一度押すと元のウィンドウに戻る |
| Windowsキー＋I | 設定を開く |
| Windowsキー＋L | PCをロックする |
| Windowsキー＋R | 「ファイル名を指定して実行」を開く |
| Windowsキー＋Tab | 開いているウィンドウや仮想デスクトップを表示する |
| Alt＋Tab | 開いているアプリを切り替える |

Alt＋Tabは、Altキーを押したままTabキーを押すたびに切り替え先を選べます。切り替えたいアプリが選ばれたら、両方のキーを離します。

## ウィンドウや画面を操作する

**Windowsキー＋←／→**を押すと、選択中のウィンドウを画面の左または右に寄せて配置できます。左右に資料やブラウザーを並べたいときに便利です。画面サイズやWindowsの設定によって、配置候補の表示が異なる場合があります。

スクリーンショットを撮るときは **Windowsキー＋Shift＋S** を押します。画面上部に出るメニューから範囲を選ぶと、画像がクリップボードにコピーされます。保存する場合は、通知を開いてSnipping Toolから保存します。

## クリップボード履歴を使う

**Windowsキー＋V**を押すと、クリップボードの履歴を表示できます。初めて使うときは、表示された画面で履歴を有効にします。その後は、履歴から以前コピーした文字などを選んで貼り付けられます。

パスワードなど人に見られたくない内容をコピーした場合は、共有PCで履歴を開かないように注意してください。履歴に表示される項目は、Windowsの設定や利用状況によって異なります。

## ショートカットが動かないとき

アプリの画面を一度クリックしてからキーを押します。文字入力欄にカーソルがある場合や、別のウィンドウが選択されている場合は、期待した操作にならないことがあります。

アプリによっては、同じキーの組み合わせに別の機能が割り当てられています。特に **Ctrl＋F** などが効かないときは、そのアプリのメニューやヘルプで操作方法を確認します。

キーボードにWindowsキーがない場合や、Fnキーを組み合わせる必要がある場合は、PCのメーカーやキーボードの説明書を確認してください。

## ワカルカモではこう使っています

最初から一覧を全部覚えようとせず、よくする作業に合わせて少しずつ使っています。文章を書くときは **Ctrl＋S** と **Ctrl＋Z**、画面を切り替えるときは **Alt＋Tab** から覚えると、普段の操作に取り入れやすいです。

## まとめ

まず覚えるなら **Ctrl＋C**、**Ctrl＋V**、**Ctrl＋Z** が便利です。エクスプローラーは **Windowsキー＋E**、アプリの切り替えは **Alt＋Tab**、スクリーンショットは **Windowsキー＋Shift＋S** で操作できます。基本の組み合わせはWindows 10でも多くが共通ですが、アプリによって動作が異なることがあります。
