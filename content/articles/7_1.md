Webサイトを作るために必ず「サーバー・ドメイン・HTMLを全部別々に用意する」わけではありません。**どの方法で作るかによって必要なものが変わります。**

## 最低限必要なのは「中身」と「公開場所」

Webサイトには、文章・画像・ページ構成などの**中身**と、それをインターネットから見られるようにする**公開場所**が必要です。

HTML/CSSで自作するなら、HTMLファイルや画像を作り、それらをレンタルサーバー、GitHub Pages、Netlifyなどへ公開します。一方、WixのようなWebサイト作成サービスでは、編集機能と公開機能がまとまっています。

## 作り方ごとに必要なもの

| 作り方 | 主に必要なもの |
| --- | --- |
| HTML/CSS＋レンタルサーバー | HTML/CSS等のファイル、サーバー、必要なら独自ドメイン |
| WordPress | レンタルサーバー、WordPress、通常は独自ドメイン |
| GitHub Pages | GitHubアカウント、リポジトリ、HTML/CSS/JS等 |
| Netlify | Netlifyアカウント、公開するファイルまたはGitリポジトリ |
| Wix | Wixアカウント、サイトに載せる文章・画像 |

## ドメインとサーバーは何をしている？

**ドメイン**は `example.com` のようなWebサイトの住所です。**Webサーバー**はHTMLや画像などを置いて、アクセスしてきたブラウザへデータを返す場所です。

独自ドメインは本格的なサイトでは便利ですが、学習や試作ならサービスから発行される無料URLでも公開できます。GitHub Pagesは既定の `github.io` URLを利用でき、Wixも公開時に無料のWix URLを利用できます。

## HTMLとCSSは必須？

自分でWebページのコードを書くなら、[HTML](7_2.html)と[CSS](7_3.html)が基本です。ただしWixやWordPressのテーマ・ブロックエディターなどを使えば、最初からすべてのコードを書く必要はありません。

## 初心者なら何から用意する？

まだ作り方が決まっていないなら、先に「何を載せたいか」「ブログのように頻繁に更新するか」「問い合わせなどの機能が必要か」を決めます。その後で[Webサイトの作り方](7.html)から公開方法を選ぶと、不要な契約を避けやすくなります。

いきなりサーバーやドメインを買う必要はありません。まず無料で試作し、続けられそうなら独自ドメインや有料プランを検討する方法でも大丈夫です。
