## 結論

Markdownでブログを書くなら、最初に覚えたいのは**見出し、箇条書き、リンク、画像、強調、コード**の基本記法です。

すべての記法を暗記する必要はありません。普段の記事で使うものから覚え、表などは必要になったときに確認すれば十分です。

## 見出し

`#`の数で見出しレベルを表します。

```markdown
# 見出し1
## 見出し2
### 見出し3
```

ブログシステム側で記事タイトルを`h1`として出力する場合、本文は`##`から始める設計もあります。

サイトのテンプレートに合わせます。

## 段落

通常の文章はそのまま書きます。

```markdown
これは1つ目の段落です。

これは2つ目の段落です。
```

空行を入れて段落を分けます。

## 箇条書き

順番のないリストは`-`などを使います。

```markdown
- HTML
- CSS
- JavaScript
```

番号付きなら次のように書けます。

```markdown
1. ファイルを作る
2. 内容を書く
3. 保存する
```

## 強調

太字は次のように書きます。

```markdown
**ここを強調します**
```

使いすぎると文章のどこが重要なのか分かりにくくなるため、ポイントへ絞ります。

## リンク

リンクは次の形です。

```markdown
[リンク文字](https://example.com/)
```

内部リンクを作る場合は、自分のサイトで確定しているURLルールに合わせます。

## 画像

基本形は次のとおりです。

```markdown
![画像の説明](/images/sample.png)
```

画像パスの解釈は、Markdownを変換するツールやサイトのディレクトリ構成によって変わります。

公開後に画像が表示されない場合は、Markdown記法だけでなく生成HTMLから見た画像URLを確認します。

## インラインコード

文中のコマンドやファイル名はバッククォートで囲めます。

```markdown
`index.html`を開きます。
```

## コードブロック

複数行のコードはバッククォート3つで囲みます。

````markdown
```html
<h1>Hello</h1>
```
````

言語名を指定すると、利用するサイトによってはシンタックスハイライトに利用できます。

## 引用

引用は`>`を使います。

```markdown
> 引用文
```

引用元がある場合は、必要に応じて出典も明記します。

## 表

Markdown処理系が対応していれば、次のような表を書けます。

```markdown
| 項目 | 内容 |
|---|---|
| HTML | ページ構造 |
| CSS | デザイン |
```

表記法は標準Markdownだけでなく拡張機能として提供される場合もあるため、利用環境で表示を確認します。

## front matterは本文記法とは別

記事ファイルの先頭に次のような情報を書く構成があります。

```yaml
---
title: "記事タイトル"
date: "2026-09-17"
---
```

これは記事本文のMarkdownとは別に、サイト生成プログラムが記事情報として読み取る部分です。

## まとめ

Markdownでブログを書くなら、見出し、段落、箇条書き、強調、リンク、画像、コードの記法から覚えます。画像パスや表などは変換環境によって挙動が異なるため、実際に生成したHTMLでも確認してください。
