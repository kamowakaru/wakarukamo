## 結論

Windows 11でスリープ時間を変えるには、**設定＞システム＞電源とバッテリー＞画面、スリープ、休止状態のタイムアウト**を開きます。画面が消えるまでの時間と、PCがスリープするまでの時間は別々に設定できます。

ノートPCでは、電源に接続しているときとバッテリーで使っているときの時間も分けて選べます。

## 画面オフとスリープの違い

**画面オフ**はディスプレイだけを消す設定です。アプリの作業は続きます。**スリープ**はPCを低電力状態にして、作業を一時中断する設定です。復帰すると、通常は開いていた作業に戻れます。

画面だけを消したいのか、PCの動作も一時中断したいのかを決めて、該当する項目を変更します。

## Windows 11でスリープ時間を変更する

1. **Windowsキー＋I**を押して設定を開きます。
2. **システム＞電源とバッテリー**を選びます。
3. **画面、スリープ、休止状態のタイムアウト**を開きます。
4. 「画面の電源を切る」と「デバイスをスリープ状態にする」から、変更したい項目を選びます。
5. バッテリー駆動時と電源接続時それぞれの時間を選びます。

設定項目の名前や並び方は、WindowsのバージョンやPCによって少し違うことがあります。見つからない場合は、設定画面の検索欄で「スリープ」や「画面の電源」と検索します。

## Windows 10で変更する

Windows 10では、次の手順で設定します。

1. **スタート＞設定＞システム＞電源とスリープ**を開きます。
2. 「画面」と「スリープ」の項目を確認します。
3. ノートPCでは「バッテリー駆動時」と「電源に接続時」それぞれの一覧から時間を選びます。

Windows 11とは設定画面の名称や構成が異なりますが、画面オフとスリープを別々に調整する点は同じです。

## 「なし」や長い時間に設定するときの注意

「なし」を選ぶと、手動で画面を消したりスリープさせたりするまで自動で切り替わらない場合があります。バッテリーの消費が増えたり、離席中も画面が表示されたままになったりするため、必要な場面だけ使いましょう。

長時間のダウンロードや処理を続けたい場合は、画面オフの時間だけ短くし、スリープまでの時間を長めにする方法もあります。ノートPCでは、バッテリー駆動中の設定を電源接続中より短めにすると、電池を使い切りにくくなります。

## 設定が変更できないとき

選択肢が表示されない、設定を変えても元に戻る場合は、会社や学校の管理設定が適用されていないか確認します。組織から支給されたPCでは、管理者が電源設定を制限していることがあります。

ノートPCのふたを閉じたときの動作は、スリープまでの時間とは別に設定されている場合があります。ふたを閉じたときだけ期待した動作にならない場合は、電源オプションの「カバーを閉じたときの動作」も確認してください。

## まとめ

Windows 11では、**設定＞システム＞電源とバッテリー**から画面オフとスリープの時間を別々に設定できます。ノートPCはバッテリー駆動時と電源接続時を分けて調整できます。Windows 10では**設定＞システム＞電源とスリープ**を開きます。
