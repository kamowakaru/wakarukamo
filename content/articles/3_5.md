## 結論

削除したファイルを戻したいときは、まず **Windowsのごみ箱**を開きます。OneDriveに保存していたファイルは、**OneDriveのWeb版のごみ箱**にも残っている可能性があります。以前からファイル履歴でバックアップしていた場合は、過去の版を確認できます。

ごみ箱にもバックアップにもない重要なファイルは、元のドライブを使い続けると復元できる可能性が下がるため、新しい保存やソフトのインストールを控えてください。

## まずWindowsのごみ箱を確認する

1. デスクトップにある **ごみ箱**を開きます。
2. ファイル名や削除日時を手がかりに目的のファイルを探します。
3. ファイルを右クリックして **元に戻す** または **復元**を選びます。
4. 元の保存先フォルダーを開き、戻ったことを確認します。

ごみ箱がデスクトップに見当たらない場合は、エクスプローラーのアドレス欄に「ごみ箱」と入力して探すか、スタートメニューから検索します。ごみ箱を空にした後や **Shift＋Delete**で削除した場合は、ここには残りません。

## OneDriveに保存していた場合

OneDriveと同期していたファイルは、PCのごみ箱に表示されない場合もあります。特にオンライン専用のファイルやWeb上から削除したファイルは、OneDriveのWeb版を確認します。

1. ブラウザーでOneDriveにサインインします。
2. 左側の **ごみ箱**を開きます。
3. 目的のファイルを選択して **復元**を押します。
4. 元のフォルダーに戻っているか確認します。

OneDriveのごみ箱にも保存期間があります。必要なファイルを見つけたら、後回しにせず復元しましょう。共有ファイルや会社・学校のアカウントでは、復元できる場所や権限が異なる場合があります。

## ファイル履歴のバックアップを確認する

削除前から **ファイル履歴**を有効にしてバックアップしていた場合は、以前の版から取り出せます。削除後に初めて設定しても、過去のファイルは作られません。

1. **Windowsキー＋E**でエクスプローラーを開き、元のファイルが入っていたフォルダーへ移動します。
2. そのフォルダーを右クリックし、**以前のバージョンの復元**を選びます。Windows 11で項目が見えない場合は **その他のオプションを表示**も確認します。
3. 削除前の日付のバージョンがあれば、内容を確認します。
4. 現在のファイルを上書きしたくない場合は、**復元先**を指定して別の場所へ復元します。

過去のバージョンが表示されない場合は、ファイル履歴にそのフォルダーのバックアップが残っていない可能性があります。外付けドライブに手動でコピーしたバックアップや、使用したアプリ内の履歴も確認してください。

## どこにもない場合は

「削除した」と思っていても、別のフォルダーへ移動しただけの場合があります。ファイル名の一部で検索する方法は[Windows 11でファイルを検索する方法](./3_3.html)で確認できます。

完全に削除したローカルファイルには、Microsoftの **Windows File Recovery**という回復ツールを試す方法があります。ただし、コマンド入力と、元のドライブとは別の保存先ドライブが必要です。復元が成功する保証もありません。特に大切なデータは、PCの使用を減らしたうえで復旧の専門業者への相談も検討してください。

## Windows 10でも使える？

Windows 10でも、ごみ箱を開いてファイルを右クリックし、**元に戻す**方法は同じです。OneDriveのWeb版のごみ箱や、以前から設定していたファイル履歴も確認できます。表示されるメニューの配置はWindows 11と異なることがあります。

## ワカルカモではこう使っています

記事のMarkdownを誤って消したときは、まずごみ箱を確認します。GitHubに公開済みの版があれば、変更履歴から以前の内容を確認できるため、ローカルのごみ箱だけに頼らず保存先ごとの履歴を見ます。

## まとめ

削除したファイルは **Windowsのごみ箱 → OneDriveのごみ箱 → 事前に作ったバックアップ**の順に確認します。どこにもない重要なファイルは、元のドライブの使用を控えて復旧方法を検討してください。Windows 10でも基本的な確認先は同じです。
