## GASでスプレッドシートを操作する基本手順

1. 操作したいGoogleスプレッドシートを開き、「拡張機能」→「Apps Script」を開きます。
2. Apps Scriptエディタへ、シートを取得して読み書きするコードを入力します。
3. 保存して、上部の実行ボタンから対象関数を実行します。
4. 初回は権限確認が表示されるため、要求内容を確認して承認します。
5. スプレッドシートへ戻り、セルの値などが意図どおり変化したか確認します。

大量データを扱う場合は、1セルずつ処理するより `getValues()` / `setValues()` などで範囲をまとめて読み書きする方が効率的です。

## セルを読み書きする基本例

```javascript
function updateSheet() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const value = sheet.getRange('A2').getValue();
  sheet.getRange('B2').setValue(value + '：確認済み');
}
```
スプレッドシートから「拡張機能 → Apps Script」を開いて貼り付けます。A2の値を読み、B2へ加工した値を書き込む最小例です。

## よくある失敗・注意点

- 操作するアカウントやサイトを取り違えたまま設定を変更する。
- 一度に複数の設定を変えて、どの変更が効いたのか分からなくなる。
- 保存・commit・公開・デプロイなど、最後の反映工程を確認せず「変わらない」と判断する。
- パスワード、APIキー、個人情報などを公開ファイルやスクリーンショットへ含める。

元に戻しにくい操作では、変更前の値やファイルを残してから進めると安全です。

## よくある質問

### GASは無料で使える？

Googleアカウントで利用できますが、サービスごとに実行時間やメール送信数などの利用上限があります。大量処理をする場合は現在のクォータを確認してください。

### コードを実行するときに許可が出るのはなぜ？

スプレッドシートやGmailなどへアクセスするスクリプトでは、初回実行時などに権限の承認が必要です。要求されている権限を確認してから許可しましょう。
