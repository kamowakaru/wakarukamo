## 結論
GASでスプレッドシートを自動処理する基本は、対象シートを取得し、`getValues()`でまとめて読み、配列上で処理して、必要な結果を`setValues()`でまとめて書く流れです。

## 例：B列が「未処理」の行を数える
```javascript
function countPending() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('記事管理');
  const values = sheet.getDataRange().getValues();

  let count = 0;
  for (let i = 1; i < values.length; i++) {
    if (values[i][1] === '未処理') count++;
  }

  console.log(`未処理: ${count}件`);
}
```
配列は0始まりなので、`values[i][1]`はB列です。1行目が見出しなら`i = 1`から始めます。

## 1セルずつ読み書きしすぎない
ループ内で毎回`getValue()`や`setValue()`を呼ぶより、範囲をまとめて読み書きするほうが実行時間を抑えやすくなります。

## まとめ
「シート取得→一括読込→配列で判定→必要なら一括書込」を基本形にすると、件数が増えても扱いやすくなります。
