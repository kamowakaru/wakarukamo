## GitHub PagesをSearch Consoleへ登録する流れ

1. Search Consoleを開き、「プロパティを追加」を選びます。
2. GitHub PagesのURLを登録するなら、まずURLプレフィックスで公開URLを入力します。
3. HTMLファイルなど利用できる所有権確認方法を選びます。
4. HTML確認ファイルを使う場合は、そのファイルをGitHub Pagesで公開される場所へ置いてPushします。
5. ブラウザから確認ファイルのURLを開けることを確かめてから、Search Consoleで「確認」を実行します。
6. 登録後はサイトマップ送信やURL検査へ進みます。

## よくある失敗・注意点

- 操作するアカウントやサイトを取り違えたまま設定を変更する。
- 一度に複数の設定を変えて、どの変更が効いたのか分からなくなる。
- 保存・commit・公開・デプロイなど、最後の反映工程を確認せず「変わらない」と判断する。
- パスワード、APIキー、個人情報などを公開ファイルやスクリーンショットへ含める。

元に戻しにくい操作では、変更前の値やファイルを残してから進めると安全です。

## よくある質問

### GitHub Pagesは無料で使える？

基本機能は無料で利用できます。ただし独自ドメインを使う場合は、ドメイン自体の取得・更新費用が別途かかります。

### 独自ドメインも使える？

はい。GitHub Pagesの設定とドメイン側のDNS設定を行えば、独自ドメインで公開できます。
