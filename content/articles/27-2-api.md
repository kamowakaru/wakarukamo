## 結論
APIキーは、API利用時に**利用者やアプリケーションを識別するために発行される文字列**です。サービスによって役割や権限は異なります。

APIキーはパスワードと同様に秘密情報として扱い、ソースコードや公開GitHubへ直接書かないようにします。

## 取得方法
取得画面はサービスごとに違います。一般的には開発者向けページでアプリ・プロジェクトを作成し、認証情報の画面から発行します。必ず利用するAPIの公式ドキュメントを確認してください。

## コードへ直接書かない
悪い例：
```python
API_KEY = "ここに本物のAPIキー"
```

公開リポジトリへPushすると第三者に使われる可能性があります。環境変数やGitHub ActionsのSecretsなど、実行環境に合った秘密情報の管理方法を使います。

Pythonなら値を環境変数から読む形にできます。
```python
import os
api_key = os.environ["API_KEY"]
```

## 漏れた可能性があるとき
単にGitHub上の文字を消すだけでは、過去のコミットに残る場合があります。まずサービス側でキーを無効化・再発行し、そのうえで公開範囲や履歴への対応を検討します。

## まとめ
APIキーは**取得することより、安全に保管して漏らさないこと**が重要です。使わなくなったキーを無効化できるかも確認しておきましょう。
