## 結論
WordPress REST APIで取得できないときは、**URL・HTTPステータス・レスポンス本文・認証の要否・セキュリティ設定**の順に切り分けると原因を探しやすくなります。

## 1. APIルートを開く
```text
https://example.com/wp-json/
```
次に、
```text
https://example.com/wp-json/wp/v2/posts
```
を確認します。

## 2. HTTPステータスを見る
404ならURLやパーマリンク・サーバー設定、401/403なら認証や権限、500番台ならWordPress・プラグイン・サーバー側エラーなどを疑います。ただしコードだけで原因を断定せず、レスポンス本文も確認します。

## 3. 公開記事か確認する
下書き・非公開記事などは認証なしで公開記事と同じようには取得できません。

## 4. セキュリティ系設定を確認する
プラグイン、WAF、Basic認証、アクセス制限などがREST APIへのリクエストを止めている場合があります。

## 5. WordPress REST APIを丸ごと無効化しない
WordPress管理機能もREST APIへ依存しています。セキュリティ目的なら「全部止める」前に、必要なアクセスだけ制限できないか確認します。

## まとめ
「REST APIが壊れた」と決めつけず、**最小のGETリクエストから一段ずつ確認**すると原因を分けやすくなります。
