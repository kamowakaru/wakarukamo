## 結論
Googleフォームの回答をGASで自動処理するなら、フォーム回答がスプレッドシートへ保存されたタイミングで動く**フォーム送信時トリガー**を使えます。

## 回答先スプレッドシートから設定する
**拡張機能 → Apps Script**で処理を書き、Apps Script画面の**トリガー**から関数を選び、イベントの種類をフォーム送信時に設定します。

## 例：送信された行をログへ出す
```javascript
function onFormSubmit(e) {
  const values = e.values;
  console.log(values);
}
```
インストール型トリガーではイベントオブジェクト`e`から送信内容を受け取れます。実際の項目順は回答シートに合わせます。

## 二重処理を防ぐ
外部API送信などを行う場合、処理済みフラグや一意IDを記録し、再実行時に同じ回答を二重処理しない設計にします。

## まとめ
フォーム自動化は「回答を受ける→必要な値を取り出す→処理→処理済みを記録」の流れにすると管理しやすくなります。
