## 結論

Webサイトを公開したら、最低限 **「正常に見られる」「Googleが見つけられる」「アクセスを確認できる」** の3段階まで整えておくと、その後の運用が楽になります。

## 公開直後の表示チェック

- [ ] トップページが公開URLで開く
- [ ] スマホでもレイアウトが崩れない
- [ ] 主要な画像が表示される
- [ ] メニュー・記事カードのリンクが開く
- [ ] 存在しないページへのリンクがない
- [ ] HTTPSで開ける
- [ ] faviconやサイト名が意図したものになっている

## Google検索向けのチェック

- [ ] Search Consoleへサイトを登録した
- [ ] 主要ページをURL検査した
- [ ] `noindex`を誤って付けていない
- [ ] robots.txtで必要なページをブロックしていない
- [ ] 必要なら`sitemap.xml`を用意した
- [ ] Search Consoleへサイトマップを送信した

[WebサイトをGoogle検索に表示させる方法](10_1.html)

## アクセス解析のチェック

- [ ] GA4などの解析ツールを設定した
- [ ] 自分でアクセスして計測できることを確認した
- [ ] プライバシーポリシーなど必要な案内を確認した

[Webサイトのアクセス数を調べる方法](10_4.html)

## 運営面のチェック

- [ ] 運営者情報を用意した
- [ ] 連絡方法を決めた
- [ ] 記事やデータのバックアップ方法がある
- [ ] 更新手順を決めた
- [ ] 公開後に直す場所を記録できる

問い合わせフォームはすべての個人サイトに必須というわけではありません。メールアドレスや別の連絡方法で十分なケースもあります。

[個人ブログにお問い合わせフォームは必要？メールだけにした理由](10_6.html)

## 公開後1〜数週間で見ること

データが少したまったら、Search Consoleで検索クエリや表示回数、GA4で読まれているページを確認します。

公開した日に全部を最適化しようとせず、実際の利用状況を見てから改善する方が無駄がありません。
