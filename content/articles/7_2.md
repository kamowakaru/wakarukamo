## 結論

HTML（HyperText Markup Language）は、**Webページに何が書かれているか、その構造を表すためのマークアップ言語**です。

たとえば「これは大見出し」「これは段落」「ここは別ページへのリンク」といった意味をタグで指定します。

## HTMLはこんなふうに書く

最小限の例なら、次のように書けます。

```html
<h1>はじめてのWebサイト</h1>
<p>これは本文です。</p>
<a href="about.html">このサイトについて</a>
```

`<h1>` は大きな見出し、`<p>` は段落、`<a>` はリンクを表します。ブラウザはこれらを読み取ってWebページとして表示します。

## CSSとの違い

HTMLとCSSは一緒に使われることが多いですが、役割は別です。

- HTML：文章や画像などの**構造・意味**を作る
- CSS：色、余白、文字サイズ、配置などの**見た目**を整える

たとえばHTMLで「これは見出し」と決め、CSSで「見出しを青くして32pxにする」と指定します。詳しくは[CSSとは？HTMLとの違いと役割](7_3.html)で解説しています。

## JavaScriptとの違い

JavaScriptは、ボタンを押したら表示を切り替える、入力内容に応じて計算する、といった**動きや処理**を加えるときに使います。

HTMLだけでも文章・画像・リンクを持つ静的なページは作れます。最初から3つ全部を完璧に覚える必要はありません。

## HTMLファイルを実際に表示してみる

Windowsならメモ帳などのテキストエディターで次を保存してみます。

```html
<!doctype html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>テストページ</title>
</head>
<body>
  <h1>こんにちは</h1>
  <p>HTMLで作ったページです。</p>
</body>
</html>
```

ファイル名を `index.html` として保存し、ブラウザで開けばページを確認できます。これはまだ自分のPC内で表示しているだけなので、他の人に見せるには[Webサイトをインターネットに公開する](7_5.html)必要があります。

HTMLは「Webサイトそのもの全部」ではなく、Webページを構成する基本材料のひとつ、と考えると分かりやすいです。
