## 100ファイルを超える更新をまとめて反映する方法

ブラウザのアップロード画面で大量ファイルを扱いにくい場合は、GitHub Desktopを使うと分かりやすいです。

1. GitHub DesktopをインストールしてGitHubへサインインします。
2. 対象リポジトリをPCへCloneします。
3. Cloneされたローカルフォルダへ、更新したファイルをまとめてコピー・置換します。
4. GitHub Desktopで変更一覧を確認してCommitします。
5. 「Push origin」でGitHubへ反映します。
6. GitHub Pagesを使っている場合はActions/Pagesのデプロイ完了後、公開サイトを確認します。

ローカルファイルを変更しただけではGitHub側は変わりません。CommitしたうえでPushするところまで必要です。

## よくある失敗・注意点

- 操作するアカウントやサイトを取り違えたまま設定を変更する。
- 一度に複数の設定を変えて、どの変更が効いたのか分からなくなる。
- 保存・commit・公開・デプロイなど、最後の反映工程を確認せず「変わらない」と判断する。
- パスワード、APIキー、個人情報などを公開ファイルやスクリーンショットへ含める。

元に戻しにくい操作では、変更前の値やファイルを残してから進めると安全です。
