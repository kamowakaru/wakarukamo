PCで作った `index.html` をダブルクリックして表示できても、それだけでは他の人は見られません。**Webからアクセスできるサーバーやホスティングサービスへファイルを置く**と、URLで公開できます。

## 方法1：レンタルサーバーへアップロードする

一般的なレンタルサーバーを使う場合は、サーバーを契約し、管理画面で接続情報を確認して、FTP/SFTPソフトなどから公開フォルダへファイルをアップロードします。

最低限 `index.html` と、そこから読み込むCSS・画像などを同じ構成でアップロードします。独自ドメインを使うなら、サーバー側へのドメイン設定も必要です。

アップロード後、設定したURLをブラウザで開いてページが表示されれば公開できています。

## 方法2：GitHub Pagesで公開する

GitHub Pagesなら、GitHubのリポジトリにサイトファイルを置き、リポジトリの **Settings → Pages** から公開元を設定できます。公開元はブランチから公開する方法と、GitHub Actionsを使う方法があります。

HTML/CSS/JavaScriptの静的サイトと相性がよく、既定の `github.io` URLでも公開できます。詳しい操作は[GitHub PagesでWebサイトを作る方法](../articles/8-1-github-pages.html)へ進んでください。

## 方法3：Netlifyで公開する

Netlifyでは既存のGitリポジトリを取り込み、公開設定をしてデプロイできます。Git連携後はpushをきっかけに再デプロイできるため、更新を自動化しやすいのが特徴です。

Gitを使わずファイルから始める方法もあります。[Netlifyとは？](7-6-github-pages.html)でGitHub Pagesとの違いも解説しています。

## 「デプロイ」とは公開環境へ反映すること

GitHub PagesやNetlifyの説明では「デプロイ」という言葉がよく出てきます。これは作成・更新したサイトを公開環境へ反映する工程です。[デプロイとは？](7-8-web.html)でビルドやアップロードとの違いを詳しく解説しています。

## WordPressやWixの場合

WordPressは通常、WordPressを設置したレンタルサーバー上でサイトが動きます。Wixはエディターの「公開」を押すことでサイトを公開します。つまり、作成サービスによってはFTPでHTMLを手動アップロードする必要はありません。

## 公開後に確認すること

公開できたら、自分のPCだけでなくスマホでもURLを開きます。画像が表示されるか、リンクが切れていないか、HTTPSになっているか、問い合わせフォームがあるなら送信できるかを確認します。

検索から見つけてもらいたい場合は、公開後にSearch Consoleやサイトマップなども設定します。公開はゴールではなく、サイト運用のスタートです。
