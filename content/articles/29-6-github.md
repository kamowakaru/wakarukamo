## 結論
GitHub Desktopは、GitのCommit・Push・Pull・Clone・履歴確認などをGUIで操作できるデスクトップアプリです。コマンド操作に慣れていない人でも、変更ファイルを見ながらGitHubを使いやすくなります。

## できること
Clone、変更差分の確認、Commit、Push、Fetch/Pull、ブランチ切り替え、履歴確認、CommitのRevertなどができます。

## ブラウザ版との使い分け
1〜2ファイルを急いで直すならブラウザでも十分です。複数ファイルをまとめて更新する、PCで生成したファイルを反映する、差分を確認してからCommitするならDesktopが便利です。

## 注意点
DesktopへZIPをそのまま入れるのではなく、Cloneしたリポジトリの実フォルダへ必要なファイルを配置します。その後Changesで差分を確認します。

## まとめ
GitHub Desktopは、**ローカルのファイル編集とGitHubの履歴管理をつなぐ画面**として考えると分かりやすいです。
