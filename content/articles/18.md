## 結論

Googleスプレッドシートの関数は、最初から大量に覚える必要はありません。初心者なら、**SUM、AVERAGE、COUNT、IF、COUNTIF、SUMIF**など、日常的な集計で使いやすい関数から覚えると実用的です。

「何を計算したいか」を先に決めてから関数を選ぶのがポイントです。

## 最初に覚えたい関数

| 関数 | 主な用途 | 例 |
| --- | --- | --- |
| SUM | 数値の合計 | `=SUM(B2:B10)` |
| AVERAGE | 平均 | `=AVERAGE(B2:B10)` |
| COUNT | 数値が入ったセルの個数 | `=COUNT(B2:B10)` |
| COUNTA | 空白でないセルの個数 | `=COUNTA(A2:A10)` |
| IF | 条件によって結果を変える | `=IF(B2>=80,"合格","確認")` |
| COUNTIF | 条件に合うセルを数える | `=COUNTIF(C2:C20,"完了")` |
| SUMIF | 条件に合う数値を合計する | `=SUMIF(A2:A20,"東京",B2:B20)` |

## SUMで合計する

売上や個数を合計したいときはSUM関数を使います。

```text
=SUM(B2:B10)
```

これはB2からB10までの数値を合計する式です。電卓で一つずつ足すより、元の数値が変わったときに自動で再計算される点が便利です。

## IFで条件によって表示を変える

点数によって「合格」「確認」を表示するならIF関数を使えます。

```text
=IF(B2>=80,"合格","確認")
```

B2が80以上なら「合格」、それ以外なら「確認」と表示します。

## COUNTIFで条件に合う件数を数える

進捗列に「完了」と書かれたセルを数えるなら次のようにします。

```text
=COUNTIF(C2:C20,"完了")
```

アンケート回答やステータス別の件数を集計するときにも使えます。

## SUMIFで条件に合う数値だけ合計する

A列が地域、B列が売上なら、特定地域だけの売上を合計できます。

```text
=SUMIF(A2:A20,"東京",B2:B20)
```

条件を指定する範囲と、合計する範囲を混同しないようにします。

## 関数でエラーが出たら確認すること

式が動かないときは、関数名だけでなく次を確認します。

- `=` から始まっているか
- 丸括弧が閉じているか
- 範囲指定が正しいか
- 文字列の条件を引用符で囲んでいるか
- 数値が文字列として入力されていないか

長い式を一気に作るより、小さな式で期待する結果になることを確認してから組み合わせます。

## まとめ

初心者は、合計ならSUM、平均ならAVERAGE、条件分岐ならIF、条件付き件数ならCOUNTIF、条件付き合計ならSUMIFというように、目的と関数をセットで覚えると使いやすくなります。
