Googleスプレッドシートの関数は、**セルの値を使って計算・判定・検索などを自動で行う仕組み**です。

関数は通常、セルへ`=`から入力します。

```gs
=SUM(B2:B10)
```

これはB2〜B10の合計を求める式です。

## 関数の基本形

多くの関数は、

```text
=関数名(引数)
```

という形です。

引数にはセル、範囲、条件、文字列などを指定します。

## 合計ならSUM

```gs
=SUM(B2:B10)
```

B2からB10までを合計します。

→ **「GoogleスプレッドシートのSUM関数の使い方」**

## 平均ならAVERAGE

```gs
=AVERAGE(B2:B10)
```

指定範囲の数値の平均を求めます。

→ **「GoogleスプレッドシートのAVERAGE関数の使い方」**

## 条件で結果を変えるならIF

```gs
=IF(B2>=80,"合格","不合格")
```

B2が80以上なら「合格」、そうでなければ「不合格」と表示します。

[GoogleスプレッドシートのIF関数の使い方](18-1-sheets.html)

## 条件に合う件数ならCOUNTIF

```gs
=COUNTIF(C2:C100,"公開済")
```

C2:C100のうち「公開済」と一致するセル数を数えます。

[GoogleスプレッドシートのCOUNTIF関数の使い方](18-2-sheets.html)

## 表から値を探すならVLOOKUP

```gs
=VLOOKUP(A2,$F$2:$H$100,3,FALSE)
```

A2の値をF列から探し、指定範囲の3列目にある値を返します。

→ **「GoogleスプレッドシートのVLOOKUP関数の使い方」**

## 数式をコピーすると参照先が変わる

`=B2*C2`を下へコピーすると、通常は`=B3*C3`、`=B4*C4`のように相対参照が動きます。

固定したいセルには`$B$2`のような絶対参照を使います。

## ワカルカモのような管理表でも便利

たとえば公開済の記事数を数える、カテゴリ別件数を集計する、別表から記事情報を引く、といったチェックを関数で自動化できます。

関数を覚えるときは大量の一覧を暗記するより、**「合計したい」「条件で判定したい」「件数を数えたい」「別表から探したい」**という目的から1つずつ覚えるのがおすすめです。
