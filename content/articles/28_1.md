## 結論

WordPress REST APIで公開記事の一覧を取得する基本URLは、通常次の形です。

```text
https://あなたのサイト/wp-json/wp/v2/posts
```

ブラウザで開くだけでも、REST APIが利用できるサイトなら公開投稿のデータをJSON形式で確認できます。

## 記事一覧のURLを開く

自分のWordPressサイトが次のURLだとします。

```text
https://example.com/
```

記事一覧の取得先は次のようになります。

```text
https://example.com/wp-json/wp/v2/posts
```

表示されたJSONには、投稿ID、公開日時、URL、タイトル、本文などの情報が含まれます。

## タイトルはtitleを確認する

1件の投稿データには複数の項目があります。

タイトルを確認したい場合は、`title`内の`rendered`を見ます。

```json
"title": {
  "rendered": "記事タイトル"
}
```

投稿を識別するときは`id`も確認しておくと便利です。

## 取得件数を変更する

一度に取得する投稿数は`per_page`パラメータで指定できます。

```text
https://example.com/wp-json/wp/v2/posts?per_page=20
```

大量の記事をすべて1回で取得するのではなく、必要に応じてページを分けます。

## 2ページ目を取得する

次のページを取得するときは`page`を指定します。

```text
https://example.com/wp-json/wp/v2/posts?per_page=20&page=2
```

記事数が多いサイトでは、`per_page`と`page`を組み合わせて順番に取得します。

## 必要な項目だけ取得する

用途によっては、投稿データのすべてが必要ではありません。

WordPress REST APIでは`_fields`を使い、返してほしい項目を絞る方法があります。

```text
https://example.com/wp-json/wp/v2/posts?_fields=id,link,title
```

記事ID、URL、タイトルだけ確認したいときに扱いやすくなります。

## 下書き記事が出ないのは正常な場合がある

認証なしで公開投稿を取得している場合、下書きや非公開投稿は公開記事と同じようには取得できません。

公開記事の一覧を確認する目的なら、返ってきたデータの公開状態を前提に扱います。

## プログラムから取得する場合

ブラウザでURLとJSONを確認できたら、GASやJavaScriptなどからHTTPリクエストを送って取得できます。

最初からコードを書き始めるより、取得URLをブラウザで確認してから実装すると、URLの間違いとコード側の問題を分けて調べやすくなります。

## まとめ

WordPress REST APIの記事一覧は、通常`/wp-json/wp/v2/posts`から取得できます。件数は`per_page`、ページは`page`、必要項目は`_fields`で調整できます。まずブラウザでJSONが返ることを確認してからプログラムへ組み込んでください。
