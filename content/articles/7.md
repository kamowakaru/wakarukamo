Webサイトを作る流れは、**①目的を決める → ②作り方を選ぶ → ③ページを作る → ④インターネットへ公開する → ⑤公開後に改善する**、の5段階です。最初からHTMLやサーバーの知識を全部覚える必要はありません。

## 1. まず「何のためのサイトか」を決める

最初に決めたいのはデザインではなく目的です。たとえば、店舗の案内、会社のサービス紹介、ブログ、作品のポートフォリオでは必要な機能が違います。

問い合わせを受けたいならフォーム、記事を頻繁に追加したいなら更新しやすい仕組み、名刺代わりの数ページだけならシンプルな静的サイトでも十分です。

## 2. 作り方を選ぶ

初心者が検討しやすい方法は次のとおりです。

| 方法 | 向いているケース | 特徴 |
| --- | --- | --- |
| Wix | コードを書かずに作りたい | 画面上で編集しやすい |
| WordPress | ブログや企業サイトを育てたい | サーバー・ドメインの準備が必要 |
| HTML/CSS | 自分で構造やデザインを作りたい | ファイルを自分で管理する |
| GitHub Pages | 静的サイトをGitHubで管理したい | HTML/CSS/JSを無料で公開しやすい |
| Netlify | 静的サイトやフロントエンドを公開したい | Git連携や自動デプロイがしやすい |

コードを書いて作りたい場合は、先に[Webサイトを作るには何が必要？](7_1-website.html)と[HTMLとは？](7_2-guide.html)を読むと全体像をつかみやすくなります。

## 3. 必要なページを作る

最初からページを増やしすぎず、目的に必要なものから作ります。会社・サービス紹介なら「トップ」「サービス」「会社・運営者情報」「問い合わせ」などが基本です。ブログなら記事一覧やカテゴリも必要になります。

スマホで見たときに文字やボタンが小さすぎないか、リンク先が間違っていないかも公開前に確認します。

## 4. インターネットへ公開する

PCの中にHTMLファイルを置いただけでは、他の人はアクセスできません。Webサーバーや公開サービスへファイルを置き、URLからアクセスできる状態にします。具体的な選択肢は[作ったWebサイトをインターネットに公開する方法](7_5-website.html)で解説しています。

独自ドメインは必須ではありません。まず無料URLで試し、サイトを本格運用すると決めてから独自ドメインへ移る方法もあります。

## 「デプロイ」って何？

Web制作では、作ったサイトを公開環境へ反映することを「デプロイ」と呼びます。GitHub PagesやNetlifyで「デプロイ」という言葉が出てきて分からない場合は、[デプロイとは？Webサイトを公開する仕組み](7_8-web.html)で、ビルド・アップロードとの違いも確認できます。

## 5. 公開したら終わりではない

公開後は実際のURLをスマホとPCで開き、表示崩れやリンク切れを確認します。検索から読んでもらいたいサイトなら、Search Consoleやアクセス解析も設定して改善していきます。

「作ること」より「誰に何を伝えるサイトなのか」が先です。目的が決まれば、WixにするかWordPressにするか、HTMLで作るかといった技術の選択もずっと簡単になります。
