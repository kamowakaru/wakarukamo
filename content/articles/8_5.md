## GitHub Pagesへ独自ドメインを設定する流れ

1. ドメイン取得サービスで独自ドメインを用意します。
2. GitHubの対象リポジトリで「Settings」→「Pages」を開きます。
3. Custom domainへ使いたいドメインを入力します。
4. ドメイン側のDNS管理画面で、GitHub Pages用のDNSレコードを設定します。
5. DNS反映後にGitHub Pagesの設定画面でドメインの状態を確認します。
6. HTTPSが利用可能になったら有効化し、独自ドメインでサイトが開くことを確認します。

## よくある質問

### GitHub Pagesは無料で使える？

基本機能は無料で利用できます。ただし独自ドメインを使う場合は、ドメイン自体の取得・更新費用が別途かかります。

### 独自ドメインも使える？

はい。GitHub Pagesの設定とドメイン側のDNS設定を行えば、独自ドメインで公開できます。
