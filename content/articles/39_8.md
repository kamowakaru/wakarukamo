## 結論

ブログを公開したら、**GA4でサイト内のアクセス、Search ConsoleでGoogle検索上の状態**を確認できるようにします。

設定コードを入れただけで終わらせず、自分でサイトを開き、データが届いていることまで確認します。

## 1. GA4のプロパティとデータストリームを作る

Google Analyticsでプロパティを作成し、Webデータストリームへ公開URLを登録します。

発行された`G-`から始まる測定IDを控えます。別サイトの測定IDを入れないよう、サイト名とURLを確認します。

## 2. 測定タグをサイトへ入れる

サイトの全ページから読み込む共通部分へ測定タグを入れます。ワカルカモでは`assets/js/analytics-config.js`に`G-`で始まるIDを設定し、共通の生成処理が出力するHTMLからそのファイルを読み込みます。ご自身のIDを設定してください。

```js
window.WAKARUKAMO_GA_MEASUREMENT_ID = 'G-自分の測定ID';
```

記事HTMLを自動生成している場合は、生成済みの全HTMLを直接修正せず、共通処理や設定ファイルを直します。公開した`articles/8_1.html`などを開き、測定に必要なタグやJavaScriptが読み込まれているかも確認します。

## 3. リアルタイムで自分のアクセスを確認する

公開サイトを別タブで開き、GA4のリアルタイム画面を確認します。

ワカルカモのGA4ホーム画面では、画面右寄りの「過去30分のアクティブユーザー数」から直近の計測状況を確認できます。下の画像はホーム画面の例で、リアルタイムレポートの操作画面ではありません。自分のアクセスを確かめるときは、このカードの下の「リアルタイムを表示」からレポートを開きます。

![ワカルカモのGA4ホーム画面。過去30分のアクティブユーザー数とリアルタイムを表示のリンクが見える](../assets/images/articles/ga4-home-realtime-link.png)

リアルタイムページでは、左のメニューで「リアルタイム ページ」が選ばれているかを見ます。画面上部に過去30分のアクティブユーザー数と表示回数、下にページパスが並びます。次の例では`/wakarukamo/`と`/wakarukamo/articles/`以下の記事が計測されています。数字は撮影時点の例なので、同じ件数になる必要はありません。

![GA4のリアルタイムページ。過去30分のユーザー数とワカルカモの記事のページパスが表示されている](../assets/images/articles/ga4-realtime-wakarukamo-pages.png)

自分で記事を1ページ開いたあとに該当パスが表示されるか確認します。表示回数はページを開いた回数、アクティブユーザーは人の数を表すため、同じ数字にはなりません。

表示されない場合は次を見ます。

- 公開ページのHTMLに測定タグが入っているか
- 測定IDが一致しているか
- 広告ブロック機能で止められていないか
- ローカルファイルではなく公開URLを開いているか
- 更新後のHTMLが公開されているか

## 4. Search Consoleへサイトを登録する

Search Consoleでプロパティを追加します。GitHub Pagesのように特定URL配下で運営する場合は、URLプレフィックスで登録する方法があります。

ワカルカモの公開URLは`https://kamowakaru.github.io/wakarukamo/`です。URLプレフィックスで登録するときは、この`/wakarukamo/`まで含むURLを指定します。所有権の確認方法としてHTMLファイルを使う場合は、指定された確認ファイルを内容や名前を変えずに公開先へ置きます。確認ファイルの公開URLがSearch Consoleの指定と合うか、ブラウザーで開いて確かめます。

## 5. URL検査でトップページを確認する

Search ConsoleのURL検査へトップページのURLを入力します。

公開直後は「Googleに登録されていません」と表示されても不自然ではありません。ページが一般公開され、Googleがアクセスできる状態かを確認します。

## 6. GA4とSearch Consoleの役割を混ぜない

| 確認したいこと | 主に使うもの |
|---|---|
| 今サイトを見ている人がいるか | GA4 |
| よく読まれるページ | GA4 |
| どんな検索語で表示されたか | Search Console |
| Googleに登録されているか | Search Console |
| 検索結果でのクリック数 | Search Console |

公開直後はデータが少ないため、数字がゼロでも設定ミスとは限りません。

## 今回の完成チェック

- GA4の測定IDを正しいサイトへ設定した
- リアルタイムで自分のアクセスを確認した
- Search Consoleの所有権確認が完了した
- URL検査でトップページを確認した
- GA4とSearch Consoleの用途を分けて見られる
