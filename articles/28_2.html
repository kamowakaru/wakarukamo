WordPress REST APIで特定の記事を取得する方法

WordPress REST APIで投稿IDやslugを使って特定の記事を取得し、タイトルやURLなどを確認する方法を解説します。

親記事

WordPress REST APIとは？できること・使い方を初心者向けに解説

結論

WordPress REST APIで特定の記事を取得する最も分かりやすい方法は、投稿IDを指定して/posts/IDへアクセスすることです。

https://example.com/wp-json/wp/v2/posts/123

投稿IDが分からずslugが分かる場合は、slugパラメータで検索できます。

投稿IDで1件取得する

投稿IDが123なら、URLは次の形です。

https://example.com/wp-json/wp/v2/posts/123

対象記事が公開されていてREST APIから取得できれば、1件分のJSONが返ります。

JSONで確認する項目

記事の照合では、たとえば次の項目を確認できます。

  • id：投稿ID
  • date：公開日時
  • modified：更新日時
  • slug：slug
  • link：記事URL
  • title：タイトル
  • content：本文
  • status：投稿状態

必要な項目だけ使います。

slugで記事を探す

slugがsample-postなら次のように指定できます。

https://example.com/wp-json/wp/v2/posts?slug=sample-post

この方法では検索結果が配列として返ります。

1件だけを想定していても、コード側では結果が0件の場合を考慮します。

必要な項目だけ返す

記事の存在とタイトルだけ確認するなら、レスポンスを絞れます。

https://example.com/wp-json/wp/v2/posts/123?_fields=id,slug,link,title

本文が長い記事では、不要なデータを減らせます。

IDと記事番号を混同しない

WordPressの投稿IDと、サイト独自の記事管理番号は別物です。

たとえば記事管理番号が28_2でも、WordPressの投稿IDが28_2になるとは限りません。

REST APIの/posts/123で使うのはWordPress側の投稿IDです。

取得できない場合

投稿IDを指定しても取得できない場合は、IDの間違い、投稿状態、REST APIへのアクセス制限などを確認します。

ブラウザで記事自体を閲覧できることと、REST APIのURLから取得できることは分けて確認してください。

まとめ

特定記事を取得するときは、WordPressの投稿IDが分かれば/wp-json/wp/v2/posts/IDを使います。slugしか分からない場合は?slug=...で検索できます。サイト独自の管理番号とWordPress投稿IDを混同しないようにしてください。

ワカルカモポイント

投稿IDが分かる場合は /posts/ID で1件を取得できます。slugから探す場合はslugパラメータを利用できます。
