WordPress REST APIとは？できること・使い方を初心者向けに解説

WordPress REST APIとは何か、できること、基本的なURL、JSON、認証、使い始めるときの確認方法を初心者向けに解説します。

結論

WordPress REST APIは、WordPressの投稿、固定ページ、カテゴリなどのデータを、外部のプログラムからHTTP経由で取得・操作するための仕組みです。

公開情報は認証なしで取得できるものがあり、投稿の作成や更新など権限が必要な操作では認証が必要です。

WordPress REST APIでできること

WordPress公式のREST APIには、投稿、固定ページ、カテゴリ、タグ、メディア、ユーザーなどを扱うエンドポイントがあります。

たとえば次のような用途に使えます。

  • 投稿一覧を取得して別の画面へ表示する
  • 外部プログラムから記事を作成する
  • 投稿内容を更新する
  • カテゴリやタグの情報を取得する
  • WordPressのコンテンツを別アプリで利用する

利用できる操作は対象データと認証権限によって変わります。

REST APIの入口を確認する

一般的なWordPressサイトでは、REST APIの情報を次のようなURLで確認できます。

https://example.com/wp-json/

example.comの部分を自分のWordPressサイトへ置き換えます。

サイト設定によってはURLの形が異なる場合があります。

投稿一覧を取得する例

投稿の基本ルートは次の形です。

https://example.com/wp-json/wp/v2/posts

ブラウザでアクセスできる公開サイトなら、JSON形式の投稿データが表示される場合があります。

個別投稿を指定するときは、投稿IDを付けます。

https://example.com/wp-json/wp/v2/posts/123

JSONでデータが返る

REST APIのレスポンスはJSON形式です。

投稿データにはID、タイトル、本文などの項目が含まれます。プログラム側では必要な項目を取り出して利用します。

GETとPOSTの違い

投稿データを取得するときはGETリクエストを使います。

新しい投稿を作成するときはPOSTなど、操作に応じたHTTPメソッドを使います。

同じ投稿ルートでも、HTTPメソッドと認証状態によって実行できる処理が変わります。

投稿作成には認証が必要

公開投稿の取得と違い、外部プログラムから投稿を作成・更新するには認証が必要です。

WordPressにはApplication Passwordsなど、外部リクエストで利用できる認証方法があります。利用する環境に適した方法を公式ドキュメントで確認します。

認証情報をソースコードや公開リポジトリへそのまま保存しないよう注意してください。

REST APIを使わなくてもよい場合

通常のWordPress管理画面だけで記事を投稿・編集するなら、REST APIを自分で操作する必要はありません。

外部プログラムから投稿を自動作成したい、WordPressのデータを別アプリへ表示したい、といった場面で検討します。

最初に試すなら取得から

初心者が仕組みを確認するときは、いきなり投稿作成を自動化するより、公開投稿の取得から試すと流れを理解しやすくなります。

  1. 自分のサイトの/wp-json/を確認する
  2. /wp-json/wp/v2/postsで投稿一覧を確認する
  3. JSONのどこにタイトルやIDがあるかを見る
  4. 取得処理をプログラムから試す
  5. 更新系の処理が必要になったら認証を設定する

まとめ

WordPress REST APIを使うと、WordPressのコンテンツをJSONで取得し、権限と認証があれば作成・更新なども行えます。まず公開投稿の取得で仕組みを確認し、その後に認証が必要な処理へ進むと理解しやすくなります。
