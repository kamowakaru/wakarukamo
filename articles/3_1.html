Windows 11でファイルの拡張子を表示する方法

Windows 11のエクスプローラーでファイル名の拡張子を表示する手順と、Windows 10での設定方法、名前変更時の注意点を解説します。

結論

Windows 11でファイルの拡張子を表示するには、エクスプローラーを開いて 表示＞表示＞ファイル名拡張子 をオンにします。たとえば「写真.jpg」「メモ.txt」のように、ファイル名の末尾まで見えるようになります。

拡張子とは

拡張子は、ファイル名の最後に付く「.jpg」「.pdf」「.txt」などの部分です。ファイルの種類を見分けたり、どのアプリで開くかを判断したりする手がかりになります。フォルダーには通常、ファイル名の拡張子は付きません。

ファイル名の例拡張子主な種類
写真.jpg.jpg画像
資料.pdf.pdf文書
メモ.txt.txtテキスト
記事.md.mdMarkdown形式のテキスト

Windows 11で拡張子を表示する

  1. Windowsキー＋E を押してエクスプローラーを開きます。
  2. 画面上部の 表示 を選びます。
  3. メニュー内の 表示 にポインターを合わせます。
  4. ファイル名拡張子 を選び、チェックを入れます。

表示中のフォルダーで「メモ.txt」のように末尾が見えれば設定完了です。拡張子を再び隠したいときは、同じ項目のチェックを外します。

Windows 10で拡張子を表示する

Windows 10では、エクスプローラーを開き、上部の 表示 タブにある ファイル名拡張子 のチェックをオンにします。ウィンドウが小さくて項目が見えない場合は、画面を広げるか、表示タブのメニューを確認してください。

名前を変更するときは末尾を残す

拡張子を表示した状態でファイル名を変更するときは、末尾の「.jpg」「.txt」などを消したり、別の拡張子に書き換えたりしないようにします。拡張子だけ変更しても、ファイルの中身が別の形式に変換されるわけではありません。

たとえば「資料.pdf」を「資料.jpg」に書き換えても、画像ファイルにはなりません。開けなくなった場合は、元の拡張子に戻すと改善することがあります。

拡張子が表示されないとき

設定をオンにしても何も変わらない場合は、ファイルではなくフォルダーを見ていないか確認します。また、もともと拡張子の付いていないファイルには、表示する末尾がありません。

「.txt.txt」のように末尾が二重に付いている場合は、名前を付けるときに入力した文字がそのままファイル名になっている可能性があります。ファイルの種類を確認してから、不要な部分だけを修正してください。

ワカルカモではこう使っています

記事の元になるMarkdownファイルを扱うときは、拡張子を表示して「.md」まで確認しています。似た名前のファイルが並んでも、テキストや画像と取り違えにくくなります。

まとめ

Windows 11では、エクスプローラーの 表示＞表示＞ファイル名拡張子 をオンにします。Windows 10では上部の 表示 タブから設定します。拡張子を表示するとファイルの種類を確認しやすくなりますが、名前変更の際は末尾を書き換えないようにしましょう。
