Search Consoleを別のGoogleアカウントで設定したときの変更方法

Search Consoleを個人用Googleアカウントで登録したあと、サイト運営用アカウントでも管理できるようにする方法を解説します。

結論

Search Consoleを個人用Googleアカウントで登録しても、サイトを作り直す必要はありません。現在の確認済みアカウントから、サイト運営用Googleアカウントをユーザーとして追加できます。

今後は運営用アカウントでログインし、権限が確認できたあと、必要に応じて個人用アカウントの権限を整理します。

アカウントを間違えても計測は壊れない

Search Consoleのデータは、登録したサイトのプロパティに蓄積されます。管理者として使うGoogleアカウントを追加しても、サイトマップや過去の検索データが最初からになるわけではありません。

大切なのは、現在のアカウントへログインできるうちに、正しい運営用アカウントを追加することです。

運営用アカウントを追加する

Search Consoleで対象プロパティを選び、設定 → ユーザーと権限を開きます。ユーザー追加から、運営用Googleアカウントのメールアドレスを指定します。

閲覧だけでなく設定も管理したい場合は、必要な権限範囲を確認して追加します。追加後、運営用アカウントへ切り替え、同じプロパティが表示されるか確認します。

Google公式の案内では、設定画面のユーザーと権限から利用者を確認・管理できます。所有者、ユーザー、権限を管理する

所有権確認ファイルは残す

HTML確認ファイルで所有権を証明している場合、そのファイルは登録時に使ったアカウントへ結び付いています。

ファイルを削除すると元の所有権へ影響する可能性があるため、アカウント整理が終わるまで残します。運営用アカウントを確認済み所有者にする場合は、そのアカウントに表示された確認方法を使います。

個人用アカウントをすぐ削除しない

運営用アカウントで次を確認してから整理します。

  • 対象プロパティを開ける
  • 検索パフォーマンスを見られる
  • サイトマップを確認できる
  • ユーザー管理に必要な権限がある

新しいアカウントで操作できることを確認せず、唯一の確認済み所有者を削除するのは避けましょう。

GA4も別に権限を確認する

Search ConsoleとGA4は別サービスです。Search Consoleへアカウントを追加しても、GA4の権限は自動で追加されません。両方を運営用アカウントで管理したい場合は、それぞれの管理画面で追加します。

まとめ

登録に使うGoogleアカウントを間違えても、プロパティを作り直す必要はありません。運営用アカウントを追加し、操作できることを確認してから、元のアカウントを残すか整理するか決めましょう。

ワカルカモポイント

プロパティを削除して最初からやり直さず、運営用アカウントをユーザーまたは所有者として追加できます。
