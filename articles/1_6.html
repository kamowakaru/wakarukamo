Windowsで画面の一部だけスクショする方法｜範囲指定してコピー・保存する手順

Windows 11で画面の一部だけを範囲指定してスクリーンショットし、コピーまたは画像として保存する方法を解説します。

結論

Windows 11で画面の一部だけをスクショするなら、Windowsキー + Shift + Sを同時に押し、画面が暗くなったら必要な範囲をドラッグします。選んだ範囲はクリップボードへコピーされるので、チャットや画像編集ソフトならそのままCtrl + Vで貼り付けられます。

画像ファイルとして残したい場合は、撮影後に表示される通知をクリックしてSnipping Toolを開き、保存します。

画面の一部だけスクショする手順

  1. スクショしたい画面を表示します。
  2. Windowsキー + Shift + Sを同時に押します。
  3. 画面上部に切り取り用のメニューが表示されたら、通常は四角形（長方形）の切り取りを選びます。
  4. 保存したい部分の左上から右下へマウスをドラッグします。
  5. マウスを離すと、その範囲がクリップボードへコピーされます。

この時点で、DiscordやChatGPT、ペイントなど貼り付けに対応した画面を開き、Ctrl + Vを押せば画像を貼り付けられます。

画像ファイルとして保存する方法

範囲を切り取ったあとにWindowsの通知が表示されたら、その通知をクリックします。Snipping Toolで撮った画像が開くので、右上の保存アイコンから保存先とファイル名を指定します。

通知を閉じてしまっても、まだクリップボードに画像が残っていればペイントなどへ貼り付けて保存できます。ただし、その後に別の内容をコピーするとクリップボードの内容が変わることがあるため、必要な画像は早めに保存しておくと安心です。

四角形以外の切り取りもできる

Windows + Shift + Sを押したあと、上部のメニューから切り取り方法を変更できます。四角形だけでなく、ウィンドウ単位や画面全体などを選べる場合があります。

「Webページのこの部分だけ」「エラー表示だけ」のように必要箇所だけ撮りたいなら、四角形の範囲指定がいちばん使いやすい方法です。

PrtScとの違い

PrtScキーは画面全体のスクリーンショットに使われることが多く、PCやWindowsの設定によってはSnipping Toolが起動します。最初から一部分だけ欲しい場合は、Windows + Shift + Sを覚えておくと余計なトリミングがいりません。

画面全体やウィンドウ単位など他の撮り方も知りたい場合は、Windows 11でスクリーンショットを撮る方法も参考にしてください。

まとめ

Windows 11で必要な範囲だけスクショするときは、Windows + Shift + S → 範囲をドラッグでOKです。すぐ使うならCtrl + Vで貼り付け、ファイルとして残すなら撮影後の通知からSnipping Toolを開いて保存します。
