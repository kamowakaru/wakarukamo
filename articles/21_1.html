GASの始め方｜スクリプトを作成・実行する方法を初心者向けに解説

GASのスクリプトを作成し、関数を保存・実行してログを確認するまでの基本手順を初心者向けに解説します。

結論

GASを始める基本手順は、Apps Scriptエディタを開く → 関数を書く → 保存する → 実行する関数を選ぶ → 実行する → 結果やエラーを確認するという流れです。

最初から複雑な自動化を作るより、ログへ文字を出す短いコードで「保存して実行する」流れを覚えると、その後のトラブルも切り分けやすくなります。

1. Apps Scriptを開く

Googleスプレッドシートから始める場合は、対象ファイルを開き、上部の「拡張機能」から「Apps Script」を開きます。

Apps Scriptのエディタが開いたら、プロジェクト名も用途が分かる名前にしておくと後から探しやすくなります。

2. 最初の関数を書く

エディタへ次のコードを入力します。

function testGAS() {
  console.log('GASを実行しました');
}

function testGAS() が関数の定義です。波括弧 { } の中に、実行したい処理を書きます。

3. 保存する

コードを入力したらプロジェクトを保存します。

文法上の問題があれば、エディタ上で警告やエラーに気付ける場合があります。括弧や引用符の閉じ忘れがないか確認します。

4. 実行する関数を選ぶ

エディタ上部の関数選択欄で testGAS を選び、実行ボタンを押します。

複数の関数を作った場合は、どの関数を実行対象として選んでいるか確認してください。

5. 初回の権限確認に対応する

スプレッドシートやGmailなど、Googleアカウントのデータへアクセスするコードでは、初回実行時などに権限確認が表示される場合があります。

要求されている権限と、自分が作成・確認したスクリプトであることを確かめてから進めます。

今回のようなログ出力だけのコードと、Gmail送信やドライブ操作を行うコードでは必要な権限が異なる場合があります。

6. 実行結果を確認する

実行後は、実行ログなどから GASを実行しました と出力されるか確認します。

エラーになった場合は、エラーメッセージと行番号を確認します。コードを丸ごと消す前に、指摘された行のスペル、括弧、引用符などを見直します。

次はスプレッドシートを操作する

基本の実行ができたら、スプレッドシートのセルを取得・更新する処理へ進めます。

最初は「特定のセルへ文字を入れる」程度の小さな処理から試し、正しく動いてからループやトリガーなどを追加すると原因を追いやすくなります。

まとめ

GASは、関数を書いて保存し、対象関数を選んで実行するのが基本です。最初はログ出力でエディタの操作と実行結果の確認方法を覚え、Googleサービスを操作するコードでは要求される権限を必ず確認してください。
