Windows 11で既定のブラウザを変更する方法

Windows 11でWebリンクを開く既定のブラウザーを変更する手順と、設定が反映されないときの確認方法を解説します。

結論

Windows 11でリンクを開くブラウザーを変更するには、設定＞アプリ＞既定のアプリを開き、使いたいブラウザーを選んで 既定値に設定 を押します。ChromeやFirefoxなど、変更先のブラウザーがPCにインストールされている必要があります。

変更前に確認すること

使いたいブラウザーがPCにインストールされ、起動できることを確認します。まだ入っていない場合は、ブラウザーの公式サイトやMicrosoft Storeなど、正規の配布元からインストールしてください。

設定から既定のブラウザーを変更する

  1. Windowsキー＋I を押して設定を開きます。
  2. アプリ＞既定のアプリ を選びます。
  3. 「アプリケーションの既定値を設定する」などの検索欄に、変更先のブラウザー名（例：Chrome）を入力します。
  4. 検索結果に表示されたブラウザーを選びます。
  5. 既定値に設定 を押します。

設定後にブラウザー名の近くに既定であることが表示されるか確認します。Windowsの更新状態によって画面の表示や項目名が異なる場合があります。

変更できたか確認する

メールやメモにあるWebリンクをひとつ開き、希望したブラウザーが起動するか確認します。ブラウザー側から「既定のブラウザーに設定しますか」と表示された場合は、Windowsの設定画面で変更した内容と食い違っていないか確認してください。

「既定値に設定」が見当たらないとき

ブラウザー名を選んだ画面に、HTTP、HTTPS、.htm、.html などのファイル形式やリンクの種類が並ぶ場合があります。その場合は、Webリンクをどのアプリで開くかを種類ごとに確認し、必要な項目を希望するブラウザーに設定します。

項目を変更する前に、今どのアプリが選ばれているか確認してください。表示内容はWindowsのバージョンやブラウザーによって異なります。迷った場合は、既定のアプリ画面でブラウザー名を検索し、表示される設定ボタンを使います。

Windows 10で変更する場合

Windows 10では、設定＞アプリ＞既定のアプリを開き、「Webブラウザー」の項目で現在のブラウザーを選び、一覧から使いたいブラウザーを選択します。Windows 11とは画面の構成が異なりますが、既定のブラウザーを設定する考え方は同じです。

まとめ

Windows 11では、設定＞アプリ＞既定のアプリから希望するブラウザーを選び、既定値に設定を押します。最後にWebリンクを開いて、変更が反映されたか確認してください。Windows 10では既定のアプリ画面にある「Webブラウザー」から選択します。
