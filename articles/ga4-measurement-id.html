GA4の測定IDはどこ？G-から始まる番号の確認方法

Google Analytics 4でG-から始まる測定IDを確認する場所と、プロパティID・ストリームIDとの違いを解説します。

結論

WebサイトへGA4を設定するときに使うのは、G-から始まる測定IDです。GA4の管理画面からデータストリームを開き、対象のウェブストリームを選ぶと確認できます。

画面にはプロパティIDやストリームIDなど複数の番号があるため、先頭の文字で見分けます。

測定IDを確認する手順

  1. Google Analyticsを開く
  2. 対象のプロパティを選ぶ
  3. 左下の管理を開く
  4. データの収集と修正にあるデータストリームを選ぶ
  5. 対象のウェブストリームを開く
  6. 測定IDを確認する

表示例は次のとおりです。

G-XXXXXXXXXX

この値をGoogleタグやサイトのGA4設定欄へ入力します。

プロパティIDとの違い

プロパティIDはGA4内のプロパティを識別する数字です。一方、測定IDはウェブデータストリームへアクセスデータを送るときに使います。

Webサイトの設定欄にG-から始まる値を求められている場合、数字だけのプロパティIDを入れても正しく計測されません。

ストリームがない場合

データストリームを開いても対象サイトがない場合は、ウェブデータストリームをまだ作成していない可能性があります。

ストリームを追加 → ウェブからサイトURLとストリーム名を入力します。サイトURLには、ブラウザで開ける公開URLを使います。

「次へ」が押せないとき

設定途中でボタンが押せない場合は、必須項目の入力漏れを確認します。

  • サイトURLのhttps://を選んでいるか
  • ドメイン・URL欄が空でないか
  • ストリーム名を入力したか
  • 入力欄に余分な空白がないか

GitHub Pagesのプロジェクトサイトでは、URLにリポジトリ名まで含まれることがあります。

測定IDを公開しても大丈夫？

測定IDはブラウザへ配信するGoogleタグ内で使うため、公開ページのソースから確認できます。パスワードとして使う情報ではありません。

一方、Googleアカウントのパスワード、APIのアクセストークン、秘密鍵は公開リポジトリへ保存してはいけません。同じ「ID」や「キー」という言葉でも扱いが異なります。

設定後に確認する

測定IDをサイトへ入れたら、GitHub Pagesへ反映し、GA4のリアルタイムレポートを開きます。詳しい確認方法は、GA4のリアルタイムにアクセスが出ないときで説明しています。

まとめ

Webサイトへ入力するGA4の番号は、ウェブデータストリーム詳細にあるG-から始まる測定IDです。似た番号を間違えないよう、データストリームからコピーしましょう。
