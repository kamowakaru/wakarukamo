Windows 11でコピー＆ペーストする方法

Windows 11で文字やファイルをコピー・移動して貼り付ける方法と、クリップボード履歴の使い方を解説します。

結論

コピーしたい文字やファイルを選んで Ctrl＋C、貼り付け先で Ctrl＋V を押します。コピー元を残さず移動したいときは Ctrl＋X のあとに Ctrl＋V を使います。

Windows 10でも同じショートカットを使えます。文字を貼るときはカーソルがある場所、ファイルを貼るときは移動先のフォルダーを開いてから操作してください。

文字をコピーして貼り付ける

  1. コピーしたい文字をドラッグして選びます。単語を選ぶ場合は、その単語をダブルクリックする方法もあります。
  2. Ctrl＋C を押します。
  3. 文字を入れたい場所をクリックして、入力カーソルを置きます。
  4. Ctrl＋V を押します。

コピーした文字は、貼り付けても元の場所に残ります。文章全体を選ぶ場合は、入力欄や文書内をクリックしてから Ctrl＋A を押します。ただし、ブラウザーではページ全体が選択されることがあるため、入力欄にカーソルがあることを確認してから使います。

ファイルをコピーして貼り付ける

ファイルを複製して別のフォルダーにも置きたいときは、次の手順です。

  1. Windowsキー＋E でエクスプローラーを開き、コピー元のファイルがあるフォルダーを表示します。
  2. 対象のファイルを一度クリックして選び、Ctrl＋C を押します。
  3. 貼り付け先のフォルダーを開きます。
  4. フォルダー内の空いている場所をクリックし、Ctrl＋V を押します。
  5. 貼り付け先にファイルができたことを確認します。

同じフォルダー内に貼り付けると、元のファイル名に「コピー」などが付いた別ファイルが作られます。別の場所にコピーする場合は、元ファイルと同じ名前で保存されることがあります。

ファイルを別のフォルダーへ移動する

元の場所から移したいときは、Ctrl＋C の代わりに Ctrl＋X を使います。

  1. 移動するファイルを選び、Ctrl＋X を押します。
  2. 移動先のフォルダーを開きます。
  3. Ctrl＋V を押します。
  4. 移動先にファイルがあることを確認します。

切り取りを押しただけで、その場でファイルが削除されるわけではありません。貼り付けが完了すると移動先へ移ります。迷ったときや大事なファイルを扱うときは、まず Ctrl＋C でコピーを作り、コピー先を確認してから元を整理すると安全です。

コピーと切り取りの違い

操作ショートカット貼り付け後
コピーCtrl＋C元の文字やファイルが残る
切り取りCtrl＋X貼り付けた文字やファイルが元の場所から移る
貼り付けCtrl＋Vクリップボードの内容を、カーソル位置やフォルダーに入れる

クリップボード履歴から前にコピーしたものを貼る

Windowsには、直近にコピーした項目を選んで貼り付ける クリップボード履歴 があります。

  1. Windowsキー＋V を押します。
  2. 初めて使うときは、画面の案内からクリップボード履歴を有効にします。
  3. 履歴に表示された項目を選びます。

通常の Ctrl＋V は直前にコピーした内容を貼りますが、履歴を使うと少し前にコピーした項目も選べます。履歴は既定では無効です。また、パスワードや住所などをコピーした場合は履歴に残ることがあるため、共有PCでは必要に応じて履歴を消してください。

うまく貼り付けられないとき

何も貼られないときは、コピーしたい文字やファイルが選択されているか、貼り付け先にカーソルがあるかを確認します。ファイルの場合は、正しいフォルダーを開いているかも見直します。

書式まで一緒に貼り付くときは、貼り付け先のアプリに「テキストのみ保持」などの貼り付けオプションがないか確認します。アプリによっては Ctrl＋Shift＋V で書式なし貼り付けができますが、すべてのアプリで使えるわけではありません。使えない場合は、いったんメモ帳に貼り付けてからコピーし直す方法があります。

前にコピーした項目を使いたいときは、Windowsキー＋V を試します。履歴が無効なら、画面の案内から有効にします。

ワカルカモではこう使っています

複数のファイルを整理するときは、移動先にファイルがあることを確かめてから、元の場所を片付けるようにします。文字を貼り付けるときも、実行前に入力カーソルが目的の欄にあるか見ておくと、別の場所へ誤って貼るのを防げます。

まとめ

元を残すなら Ctrl＋C、移動するなら Ctrl＋X、貼り付けるときは Ctrl＋V です。文字はカーソル位置、ファイルは移動先フォルダーを確認してから貼り付けます。以前コピーした項目は Windowsキー＋V の履歴から選べます。
