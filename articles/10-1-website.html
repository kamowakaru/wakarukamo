WebサイトをGoogle検索に表示させる方法

WebサイトをGoogle検索に表示させる方法について、初心者向けに具体的な手順・例・注意点を交えて解説します。

WebサイトをGoogle検索に表示させるには、まずGoogleがページへアクセスでき、インデックス登録できる状態にすることが必要です。

Search Consoleへの登録やインデックス登録リクエストは役立ちますが、リクエストしたから必ず検索結果へ表示されるわけではありません。

1. ページを一般公開する

ログインしないと見られないページや、noindexが設定されたページは通常の検索掲載には向きません。

まず公開URLをシークレットウィンドウなどで開き、誰でも閲覧できることを確認します。

2. Search Consoleへサイトを登録する

Google Search Consoleを開き、対象サイトのプロパティを追加して所有権を確認します。

GitHub Pagesなど、HTMLファイルを設置できるサイトではHTML確認ファイルを使う方法もあります。

3. URL検査でページを確認する

Search Console上部のURL検査に、公開したページの完全なURLを入力します。

未登録の新規ページなら、ライブURLに問題がないことを確認したうえで 「インデックス登録をリクエスト」 を使えます。

ただし、Google公式でもリクエストはインデックス登録を保証するものではないと案内されています。

4. ページが多いならサイトマップを送信する

記事が増えるサイトでは、sitemap.xmlを作成し、Search Consoleの 「サイトマップ」 からURLを送信します。

サイトマップは「Googleへファイルをアップロードする」のではなく、自分のサイトに置いたサイトマップの場所をGoogleへ伝える仕組みです。

5. 内部リンクも用意する

Googleは既知のページからリンクをたどって新しいページを見つけることもあります。

トップページ、カテゴリページ、関連記事などから新しい記事へ移動できる状態にします。

表示されないときに確認すること

Search ConsoleのURL検査で、

  • GoogleがURLを認識しているか
  • クロールできるか
  • noindexになっていないか
  • 別URLの重複ページとして扱われていないか

を確認します。

インデックス済みでも、すべての検索で必ず表示されるわけではありません。検索語との関連性や検索結果の状況によって掲載位置は変わります。
