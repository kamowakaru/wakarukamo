Windows 11でアプリをインストール・アンインストールする方法

Windows 11でMicrosoft Storeや公式サイトからアプリを入れる方法と、不要になったアプリを削除する手順を解説します。

結論

アプリを入れるときは、まず Microsoft Store で探します。見つからないデスクトップソフトは、開発元や販売元の公式サイトから入手します。不要になったアプリは、スタートメニューまたは設定からアンインストールできます。

アンインストールしても、アプリのアカウントやクラウド上のデータ、契約中のサブスクリプションが自動で解約されるとは限りません。削除前に、保存データ・ライセンス・定期購入の扱いを確認してください。

Microsoft Storeからインストールする

  1. スタート を開き、「Microsoft Store」と入力してアプリを開きます。
  2. Store内で、入れたいアプリの名前を検索します。
  3. 検索結果からアプリを選び、名称・発行元・料金・必要な機能を確認します。
  4. 入手 または インストール を選び、画面の案内に従います。ボタンの表示はアプリや購入状況によって異なります。
  5. インストール後、スタートメニューからアプリを探して起動します。

StoreのアプリはStore内から更新できます。Storeに目的のアプリがない場合は、同じ名前の別アプリを急いで入れず、開発元の公式サイトで提供方法を確認します。

公式サイトからデスクトップアプリを入れる

  1. アプリの開発元・販売元の公式サイトを開きます。検索広告やダウンロードまとめサイトではなく、会社名や製品名を確認して正規の配布ページへ進みます。
  2. Windows用のインストーラーをダウンロードします。対応するWindowsの版、システム要件、料金、試用期間を確認します。
  3. ダウンロードしたファイルを開き、画面に表示される発行元やアプリ名を確かめます。
  4. 問題がなければセットアップを進めます。途中で追加ソフト、起動時の自動実行、既定アプリの変更などを選ぶ画面が出たら、内容を読んで必要な項目だけ選びます。
  5. 完了後、スタートメニューからアプリを起動します。

インストーラーを実行するときに管理者の確認が表示されることがあります。発行元やアプリ名に心当たりがない場合は、許可せず、ダウンロード元を確認してください。会社や学校のPCで管理者パスワードを求められた場合は、組織のルールに従います。

アプリをアンインストールする

スタートメニューから削除する

  1. スタート を開き、すべてのアプリ から削除したいアプリを探します。
  2. アプリを右クリックします。
  3. アンインストール を選び、画面の指示に従います。

設定から削除する

  1. Windowsキー＋I で設定を開きます。
  2. アプリ＞インストール済みアプリ を開きます。
  3. 一覧から削除するアプリを探し、右側の … から アンインストール を選びます。
  4. 確認画面が表示されたら、アプリ名を確認して続行します。

設定にアンインストールの項目がないデスクトップソフトは、スタートから「コントロール パネル」を検索し、プログラム＞プログラムと機能 から削除できる場合があります。Windowsに組み込まれた一部のアプリは削除できません。

削除前に確認したいこと

  • アプリ内だけに保存した文書・設定・プロジェクトがあれば、別の場所へ保存する。
  • 有料アプリのライセンスキーや、再インストール時に必要なアカウント情報を確認する。
  • 月額・年額の契約がある場合は、アプリの削除とは別に契約の解約手続きを確認する。
  • 「修復」や「リセット」で直せる問題なら、先にその選択肢を検討する。

アプリ本体を削除した後も、個人データや設定がPCに残ることがあります。削除後にデータも消したい場合は、アプリの案内や開発元のサポートで保存場所と手順を確認します。

インストールや削除ができないとき

Storeにアプリが出てこない場合は、地域・対応OS・PCの要件によって提供対象外のことがあります。開発元の公式ページで対応状況を確認します。

インストールで管理者パスワードを求められる場合は、管理者権限が必要なソフトの可能性があります。自分のPCなら管理者アカウントを確認し、会社や学校のPCなら管理担当者に確認します。

アンインストール項目が見当たらない場合は、設定ではなくスタートメニューやコントロール パネルから削除できるか確認します。アプリによって削除方法が異なります。

ワカルカモではこう使っています

新しいソフトを試す前に、配布元の公式ページで対応OSと必要な機能を確認します。使わなくなったソフトを整理するときも、先にアプリ内のデータやライセンスを確認してから削除する流れにしています。

まとめ

アプリはMicrosoft Store、または開発元・販売元の公式サイトから入手します。削除はスタートメニューや 設定＞アプリ＞インストール済みアプリ から行い、設定から消せないデスクトップソフトはコントロール パネルを確認します。アンインストール前には、データ・ライセンス・契約を確認してください。
