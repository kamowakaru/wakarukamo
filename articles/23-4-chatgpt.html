ChatGPTの過去のチャットを探す方法

ChatGPTで以前の会話を検索して見つける方法と、タイトルを覚えていないときの検索語の選び方を解説します。

結論

以前のChatGPTの会話を探すときは、サイドバーの検索を開き、チャット内で使ったキーワードを入力します。

タイトルを正確に覚えていなくても、会話に出てきたサービス名・エラー文・固有名詞など、特徴的な言葉から探すのがコツです。

過去のチャットを検索する手順

  1. ChatGPTを開きます。
  2. 左側のサイドバーから検索を開きます。
  3. 探している会話に含まれていそうな言葉を入力します。
  4. 検索結果から目的のチャットを選びます。

現在のChatGPTでは、検索機能からチャットだけでなくプロジェクトやファイルなども横断して探せる場合があります。

見つからないときは検索語を変える

たとえば「GitHubの記事を作っていた会話」を探すなら、

GitHub

だけでは候補が多くなることがあります。

会話中に出てきた、

Revert
generate_site.py

のような特徴的な語を試すと絞り込みやすくなります。

文章を丸ごと覚えていなくても大丈夫です。「その会話でしか使っていなさそうな言葉」を思い出してみましょう。

長く続くテーマはプロジェクトにまとめる方法もある

同じサイト制作や勉強などで何度もチャットを作るなら、後から毎回検索するよりプロジェクトへまとめる方法もあります。

プロジェクトについてはChatGPTのプロジェクトとは？使い方を初心者向けに解説で解説しています。

まとめ

過去チャットは、サイドバー検索＋特徴的なキーワードで探します。タイトルだけに頼らず、会話中の固有名詞やエラー文で探すのがポイントです。
