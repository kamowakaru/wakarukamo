WordPressでリンクを貼る方法｜内部リンク・外部リンクを解説

WordPressでリンクを貼る方法について、初心者向けに具体的な手順・例・注意点を交えて解説します。

WordPressで文字へリンクを貼るには、リンクにしたい文字を選択 → リンクアイコン → 自サイトの記事を検索するかURLを入力します。

1. リンクにしたい文字を選択する

投稿・固定ページの編集画面で、リンクにしたい文字をドラッグして選択します。

ブロックのツールバーに表示されるリンクアイコンを押します。

キーボードならWindowsで Ctrl + K、Macで Command + K が使える環境もあります。

2. 内部リンクなら記事を検索する

自分のWordPressサイト内の記事へリンクする場合は、リンク欄へ記事タイトルなどを入力します。

候補に目的の記事が表示されたら選択します。

たとえば、

WordPressのパーマリンク設定については「WordPressのパーマリンクとは？おすすめ設定を解説」で詳しく説明しています。

のように、リンク先の内容が分かる文字へリンクを設定すると親切です。

「こちら」だけをリンクにするより、どこへ移動するのか分かりやすくなります。

3. 外部リンクならURLを入力する

別サイトへリンクする場合は、

https://example.com/...

のような完全なURLを貼り付けます。

入力後、候補または確定操作を選んでリンクを設定します。

4. 新しいタブで開く設定は必要なときだけ

リンクの詳細設定では、新しいタブで開く設定を選べる場合があります。

外部リンクだから必ず新規タブ、内部リンクだから必ず同じタブ、という絶対ルールはありません。読者の操作を必要以上に変えないよう、サイト全体で方針をそろえます。

内部リンクと外部リンクの違い

内部リンクは同じサイト内の別ページへのリンクです。

example.com/article-a/
→ example.com/article-b/

外部リンクは別ドメインのサイトへのリンクです。

example.com/
→ wordpress.org/

内部リンクは、関連情報や次の作業へ読者を案内するのに役立ちます。

公開前に実際にクリックする

リンク設定後はプレビューまたは公開ページでクリックし、

  • 404にならない
  • 別の記事へ間違って飛ばない
  • httpとhttpsを間違えていない
  • URLの末尾まで正しく入っている

ことを確認します。

リンクは「設定できた」だけでなく、目的のページが実際に開くことまで確認して完了です。
