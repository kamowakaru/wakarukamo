GitHub PagesにGA4を設定する方法｜測定開始までの手順

GitHub Pagesで公開したサイトにGA4を設定し、測定IDの確認からタグ設置、リアルタイムでの動作確認までを解説します。

結論

GitHub PagesにGA4を設定する基本手順は、GA4でWebデータストリームを作る → G- から始まる測定IDを確認する → サイトのHTMLへGoogleタグを追加する → GitHubへ反映して再公開する → GA4のリアルタイムで確認するという流れです。

GitHub Pages側にGA4専用の入力欄があるとは限らないため、静的HTMLサイトではサイトのコードへタグを実装する方法が基本になります。

1. GA4のWebデータストリームを用意する

Google Analyticsで対象のGA4プロパティを開き、GitHub PagesのサイトURLを対象としたWebデータストリームを確認または作成します。

Webストリームの詳細には G- から始まる測定IDがあります。別サイトのストリームと間違えないよう、URLとストリーム名も確認します。

2. Googleタグを確認する

Webデータストリームの案内からGoogleタグの実装方法を確認します。

表示されたコードを使う場合は、測定IDが自分のWebストリームのものになっていることを確認してください。サンプルのIDをそのまま使わないようにします。

3. HTMLへタグを追加する

静的HTMLで作ったサイトなら、Googleの案内に従って各ページで読み込まれるHTMLの適切な位置へタグを追加します。

複数ページがある場合は、トップページだけでなく計測対象ページでもタグが読み込まれる構成にします。共通テンプレートを使っているサイトでは、テンプレート側へ追加する方が管理しやすい場合があります。

4. GitHubへ変更を反映する

タグを追加したファイルを保存し、GitHub Pagesの公開元になっているリポジトリへ変更を反映します。

GitHub Pagesのデプロイが完了したら、公開URLを開いて更新後のサイトが表示されることを確認します。

5. GA4のリアルタイムで確認する

GA4のリアルタイムレポートを開いた状態で、公開したGitHub Pagesへアクセスします。

ページ表示などのイベントが届けば、計測開始を確認できます。反映されない場合は、測定ID、タグの配置、公開したファイル、ブラウザ拡張機能などを順に確認します。

二重設置に注意する

すでにGoogleタグマネージャーやサイト生成ツール側の設定でGA4を導入している場合は、さらに同じGA4タグをHTMLへ直接追加すると重複計測になる可能性があります。

新しいタグを追加する前に、現在のHTMLやテンプレートを検索して既存のGoogleタグがないか確認します。

プライバシー対応も確認する

GA4を設置する場合は、サイトの対象地域や利用している機能に応じて、プライバシーポリシーや同意管理についても確認が必要です。

タグが動いたことだけで設定完了とせず、実際の運用に必要な開示や設定も確認してください。

まとめ

GitHub PagesへのGA4導入では、正しい測定IDのGoogleタグをサイトへ実装し、変更を公開した後にリアルタイムで動作確認します。表示されないときは、GA4側だけでなくGitHub Pagesへ最新HTMLが公開されているかも確認してください。
