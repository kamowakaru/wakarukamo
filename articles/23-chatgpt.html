ChatGPTの使い方｜基本操作と便利な機能を初心者向けに解説

ChatGPTの基本的な使い方を、質問の送り方から画像・ファイル・Web検索・過去チャット・プロジェクトまで初心者向けに整理します。

結論

ChatGPTは、入力欄に質問や依頼を書いて送信し、返ってきた回答に追加で指示するのが基本です。最初から完璧な質問を書く必要はありません。

たとえば「Windows 11でスクリーンショットを撮る方法を教えて」と送ったあと、「範囲指定だけ知りたい」「画像はどこに保存される？」と続ければ、同じ会話の流れで絞り込めます。

さらに、文章だけでなく画像やファイルを渡したり、最新情報が必要な質問ではWeb検索を使ったりできます。

ChatGPTの基本操作

  1. ChatGPTを開きます。
  2. 画面下部の入力欄に、知りたいことやしてほしいことを書きます。
  3. 送信します。
  4. 回答を読み、足りない部分があればそのまま追加で質問します。
  5. 別の話題へ切り替えたいときは新しいチャットを作ります。

質問は「○○について教えて」だけでも始められます。ただし、目的や条件を足すほど回答を絞りやすくなります。

GitHub Pagesについて教えて

GitHub PagesでHTMLサイトを公開したいです。
GitHub初心者向けに、最初に作るリポジトリから順番に教えてください。

のほうが、欲しい回答に近づきやすくなります。

便利な機能は必要になったときに使えばOK

画像を見せて質問する

画面のスクリーンショットや写真を添付すると、「この画面のどこを押す？」「このエラー表示は何？」のように質問できます。

詳しい操作はChatGPTに画像を送って質問する方法で解説しています。

ファイルを読んでもらう

PDFや文書、表計算ファイルなどを添付し、要約・比較・情報抽出などを頼めます。

詳しくはChatGPTにファイルを送って内容を読み取る方法を確認してください。

Web検索を使う

現在の料金、最近のニュース、現行サービスの仕様など、最新情報が必要な質問ではWeb検索が役立ちます。

使い方はChatGPTでWeb検索する方法で解説しています。

過去の会話を探す

以前のチャットを探したい場合は、サイドバーの検索からキーワードで探せます。

ChatGPTの過去のチャットを探す方法では、見つけやすい検索語の考え方も紹介しています。

長く続く作業はプロジェクトにまとめる

同じテーマで何度もChatGPTを使うなら、プロジェクトに関連チャットやファイルをまとめる方法があります。

詳しくはChatGPTのプロジェクトとは？使い方を初心者向けに解説へ進んでください。

ChatGPTを使うときの注意点

ChatGPTの回答は、常に正しいとは限りません。特に料金、制度、サービスの現行仕様、医療・法律・お金など重要な情報は、元となる公式情報も確認します。

また、公開してはいけないパスワード、APIキー、社外秘、他人の個人情報などを、そのまま入力しないようにします。

まとめ

ChatGPTは、まず質問を書く→回答を見る→追加で質問するだけ覚えれば使えます。画像、ファイル、Web検索、プロジェクトなどは、必要になったときに一つずつ使えば十分です。
