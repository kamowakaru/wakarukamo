GASでメールを自動送信する方法｜Gmailを使った基本例を解説

GASからGmailを使ってメールを送信する基本コードと、宛先・件名・本文の設定、テスト時の注意点を解説します。

結論

GASでGmailからメールを送信する基本例では、GmailApp.sendEmail() を使って宛先・件名・本文を指定します。

最初から顧客一覧などへ一括送信せず、自分で確認できる宛先へ1通だけ送り、本文や実行回数が正しいことを確認してから自動化してください。

基本的なメール送信コード

次のようなコードでメールを送信できます。

function sendTestMail() {
  const to = 'your-address@example.com';
  const subject = 'テストメール';
  const body = 'GASから送信したテストメールです。';

  GmailApp.sendEmail(to, subject, body);
}

your-address@example.com は、実際にテストで使用するメールアドレスへ変更します。

コードを実行する

コードを保存し、実行する関数として sendTestMail を選んで実行します。

Gmailへのアクセスを伴うため、初回実行時などには権限の確認が表示される場合があります。要求内容を確認してから承認します。

スプレッドシートの値を本文に使う

スプレッドシートから取得した値をメール本文へ組み込むこともできます。

たとえばA2セルの名前を取得して本文へ入れる、といった処理です。いきなり複数行をループせず、最初は1行分だけ取得して期待する文章になるか確認します。

自動送信するならトリガーを確認する

時間主導型トリガーを使えば、定期的なメール送信もできます。

ただし、同じ関数に複数のトリガーを設定すると重複送信につながる可能性があります。自動化前にトリガー一覧を確認します。

送信数には上限がある

Apps ScriptやGoogleサービスには利用量に関する割り当てや制限があります。利用しているアカウントや機能によって条件が異なるため、大量送信を設計する場合は最新の公式ドキュメントで上限を確認してください。

個人情報をログへ出しすぎない

メールアドレスや本文に個人情報を含む場合は、デバッグのためにすべてをログへ出力する設計にも注意が必要です。

必要な情報だけを扱い、共有スクリプトでは誰がコードや実行情報を見られるかも確認します。

まとめ

GASでは GmailApp.sendEmail() を使ってメールを送信できます。まず1通だけテストし、宛先・件名・本文・権限を確認してから、スプレッドシート連携やトリガーによる自動化へ進んでください。

ワカルカモポイント
