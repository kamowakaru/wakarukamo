GASでメールを自動送信する方法｜Gmailを使った基本例を解説

GASでメールを自動送信する方法について、初心者向けに具体的な手順・例・注意点を交えて解説します。

GASではGmailApp.sendEmail()を使うと、Gmailからメールを送信できます。まずは自分宛てなど少数でテストしてから自動化するのが安全です。

基本の送信コード

function sendMail() {
  GmailApp.sendEmail(
    'example@example.com',
    'テストメール',
    'GASから送信した本文です。'
  );
}

順番は 宛先、件名、本文 です。

初回実行時はGmailへのアクセス権限を求められるため、内容を確認して承認します。

シートの値を本文に使う

function sendMailFromSheet() {
  const sheet = SpreadsheetApp
    .getActiveSpreadsheet()
    .getSheetByName('シート1');

  const name = sheet.getRange('A2').getValue();
  const address = sheet.getRange('B2').getValue();

  const subject = 'お知らせ';
  const body = `${name}さん
確認をお願いします。`;

  GmailApp.sendEmail(address, subject, body);
}

これでシートのA2を名前、B2を宛先として使えます。

HTMLメールも送れる

GmailApp.sendEmail()のオプションでhtmlBodyを指定するとHTML本文も利用できます。ただし、最初はプレーンテキストで動作確認してから広げる方が原因を切り分けやすいです。

自動送信前に確認すること

宛先列のずれ、空欄、重複送信は特に危険です。「送信済み」列を持たせる、テストモードでは自分宛てにするなど、二重送信を防ぐ仕組みを入れます。

GmailやApps Scriptには送信・実行の割り当てがあります。大量配信サービスの代わりとして無制限に送れるわけではありません。
