Windows 11でZIPファイルを圧縮・解凍する方法

Windows 11の標準機能で複数のファイルをZIPにまとめる方法と、受け取ったZIPを展開する方法を解説します。Windows 10での操作も紹介します。

結論

Windows 11では、まとめたいファイルを選んで右クリックし、ZIPファイルに圧縮するを選ぶと、ひとつのZIPファイルにできます。受け取ったZIPは右クリックして すべて展開を選び、取り出し先を指定します。Windowsの表示によっては「すべて抽出」という名前です。

ZIPは複数のファイルをひとつにまとめる形式です。元のファイルは残るので、ZIPを作っただけでは元データは移動・削除されません。

複数のファイルをZIPにまとめる

  1. Windowsキー＋Eでエクスプローラーを開き、まとめたいファイルのあるフォルダーへ移動します。
  2. ファイルを複数選びます。離れた位置のファイルを選ぶときは、Ctrlキーを押しながらクリックします。
  3. 選択したファイルのどれかを右クリックし、ZIPファイルに圧縮するを選びます。
  4. 同じ場所に作られたZIPの名前を確認し、必要なら分かりやすい名前に変更します。

「ZIPファイルに圧縮する」が見当たらない場合は、右クリックメニューの その他のオプションを表示＞送る＞圧縮（zip形式）フォルダーを探してください。Windowsの更新状態によってメニューの表示が異なります。

フォルダーを丸ごとZIPにしたい場合は、フォルダーを右クリックして同じ操作をします。ZIPの中にそのフォルダーが入る形になります。

ZIPファイルを解凍・展開する

  1. 受け取った .zip ファイルをエクスプローラーで探します。
  2. ZIPを右クリックして、すべて展開またはすべて抽出を選びます。
  3. 展開先を指定して、展開ボタンを押します。
  4. 作成されたフォルダーを開き、必要なファイルが揃っているか確認します。

ZIPをダブルクリックすると中身を一覧で見られます。中のファイルを実際に編集したり、まとめて使ったりするときは、先に展開してから作業すると保存場所を把握しやすくなります。ひとつのファイルだけ取り出す場合は、ZIPを開いて別のフォルダーへドラッグする方法もあります。

Windows 10での操作

Windows 10では、ファイルやフォルダーを選んで右クリックし、送る＞圧縮（zip形式）フォルダーを選びます。ZIPを取り出す手順は、ZIPを右クリックして すべて展開を選ぶ方法が基本です。

よくある疑問

ZIPにすると必ず容量が小さくなる？

ファイルの種類によります。JPEG画像や動画のように、もともと圧縮されているファイルは、ZIPにしても容量がほとんど変わらないことがあります。複数のファイルをひとつにまとめて渡せる点もZIPの利点です。

パスワード付きZIPも標準機能で作れる？

Windows標準のZIP機能だけでは、暗号化したZIPの作成・展開に対応しない場合があります。パスワード付きZIPが必要なら、対応する圧縮ソフトを使い、受け取る相手が展開できる形式かも確認してください。機密情報を入れる場合は、共有方法と保存先も確認します。

展開したはずのファイルが見つからない

展開時に指定した保存先を確認します。通常は、ZIPの近くに同名のフォルダーが作られます。エクスプローラーでZIP名の一部を検索する方法もあります。

まとめ

Windows 11では、ファイルを選んで右クリックするとZIPに圧縮できます。展開するときはZIPを右クリックし、すべて展開を選びます。Windows 10では 送る＞圧縮（zip形式）フォルダーから作成できます。作成後・展開後は中身を確認しましょう。
