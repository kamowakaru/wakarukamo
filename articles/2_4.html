Windows 11でスタートアップアプリを無効にする方法

Windows 11でサインイン時に自動起動するアプリを確認し、不要なものを無効にする方法をWindows 10の手順とあわせて解説します。

結論

Windows 11では、設定＞アプリ＞スタートアップから、サインイン時に自動で起動するアプリをオフにできます。無効にしてもアプリがアンインストールされるわけではなく、必要なときに手動で起動できます。

設定からスタートアップアプリを無効にする

  1. Windowsキー＋Iを押して設定を開きます。
  2. アプリ＞スタートアップを選びます。
  3. 自動起動を止めたいアプリのスイッチをオフにします。

再び自動起動させたい場合は、同じ一覧でスイッチをオンに戻します。

タスクマネージャーから変更する

タスクマネージャーでは、アプリが起動時に与える影響も確認できます。

  1. スタートボタンを右クリックして、タスクマネージャーを開きます。
  2. スタートアップアプリを選びます。
  3. 対象のアプリを選び、無効化を押します。

「スタートアップへの影響」は、起動時の処理がPCに与える負荷の目安です。影響が大きいアプリでも、必要なものなら無効にする必要はありません。設定の一覧とタスクマネージャーの一覧は、表示内容が少し異なる場合があります。

どのアプリを無効にするか迷ったら

毎回使わないチャットアプリやゲームランチャーなどは、アプリ名と用途を確認してから無効化を検討できます。一方、用途が分からない項目や、セキュリティ・バックアップ・周辺機器の機能に関係しそうな項目は、名前だけで判断せず、アプリの提供元やPCメーカーの説明を確認します。

一度に多くのアプリを無効にするのではなく、候補をひとつ変更してから再起動し、必要な機能に影響がないかを確かめると戻しやすくなります。自動起動を止めると、アプリを自分で開くまで通知や同期が始まらない場合があります。

Windows 10で変更する

Windows 10でも、対応しているバージョンでは 設定＞アプリ＞スタートアップから同じようにスイッチをオフにできます。設定内で見つからない場合は、Ctrl＋Shift＋Escでタスクマネージャーを開き、スタートアップタブでアプリを選んで無効にするを押します。

アプリが一覧に見当たらないとき

すべてのアプリが設定やタスクマネージャーの一覧に表示されるとは限りません。アプリ内に「Windows起動時に実行する」設定がある場合は、そちらを確認します。スタートアップフォルダーに登録されているケースもありますが、分からないショートカットやシステム設定はむやみに削除しないでください。

まとめ

スタートアップアプリは、設定またはタスクマネージャーから無効にできます。オフにしてもアプリ自体は削除されません。用途が分かるものからひとつずつ見直し、必要なアプリや機能に影響がないか確認してください。
