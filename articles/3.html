Windows 11のファイル・フォルダ操作まとめ｜保存・移動・圧縮・検索を解説

Windows 11のファイル操作で迷いやすい拡張子、ZIP、検索、一括リネーム、削除ファイルの復元を目的別に案内します。

結論

ファイル操作で困ったときは、まず「種類を確認したい」「ZIPでまとめたい」「見つからない」「名前を一括で変えたい」「削除したものを戻したい」のどれに当てはまるか選びます。このページから、Windows 11の各操作を説明する記事へ進めます。

Windows 10でも多くの基本操作は同じですが、エクスプローラーのボタン名やメニューの位置が異なる場合があります。

ファイルの種類を確認したい

ファイル名の末尾にある「.jpg」「.pdf」などは拡張子と呼ばれ、ファイルの種類を見分ける手がかりになります。拡張子を表示すると、似た名前のファイルを区別しやすくなります。

Windows 11でファイルの拡張子を表示する方法

複数のファイルをまとめて送りたい

複数のファイルをZIP形式にまとめると、ひとつのファイルとして扱いやすくなります。受け取ったZIPは、展開して中のファイルを取り出します。

Windows 11でZIPファイルを圧縮・解凍する方法

保存場所が分からないファイルを探したい

エクスプローラーやタスクバーの検索を使うと、ファイル名の一部から探せます。保存場所が分かる場合は、そのフォルダーを開いてから検索すると候補を絞りやすくなります。

Windows 11でファイルを検索する方法

複数のファイル名をまとめて変えたい

写真や資料など、同じ規則で名前を付け直したいときは、エクスプローラーの一括変更が便利です。変更後の名前を確認してから実行すると、意図しない連番になってしまうのを防ぎやすくなります。

Windows 11でファイル名を一括変更する方法

削除したファイルを戻したい

まずごみ箱を確認します。ごみ箱にもないファイルは、バックアップやクラウドのごみ箱など、保存先に応じた復元方法を探します。復元ソフトを使う場合は、元のファイルがあったドライブへの新しい保存をできるだけ控えてください。新しいデータが書き込まれると、復元できる可能性が下がる場合があります。

Windows 11で削除したファイルを復元する方法

操作前に知っておきたいこと

ファイル名の変更や移動、削除を行う前に、対象の名前と保存場所を確認します。大切なデータは別の場所やクラウドにもバックアップを作っておくと、誤操作やPCの故障に備えられます。

Windows 11では、エクスプローラーの右クリックメニューがWindows 10と異なることがあります。見当たらない項目は その他のオプションを表示から探すか、エクスプローラー上部のメニューを確認してください。

まとめ

拡張子を表示すると種類を確認しやすくなり、ZIPは複数ファイルの受け渡しに使えます。検索、一括変更、削除ファイルの復元も、目的に合った手順を選んで進めましょう。各操作の詳しい説明は、上の個別記事で確認できます。
