GoogleスプレッドシートのSUMIF関数の使い方

GoogleスプレッドシートのSUMIF関数の使い方について、初心者向けに具体的な手順・例・注意点を交えて解説します。

IF関数は、条件が成立するかどうかで表示する結果を変える関数です。

基本形は次のとおりです。

=IF(条件, 条件が成立したとき, 成立しないとき)

点数で合否を判定する

B2が80以上なら「合格」、それ以外なら「不合格」にする例です。

=IF(B2>=80,"合格","不合格")

>=は「以上」を表します。

文字列が一致するか判定する

C2が「公開済」なら○を表示する例です。

=IF(C2="公開済","○","")

成立しない場合の""は空文字列なので、見た目上は空欄になります。

よく使う比較演算子

=   等しい
<>  等しくない
>   より大きい
>=  以上
<   より小さい
<=  以下

文字列を条件にするときは"公開済"のようにダブルクォーテーションで囲みます。

IFを何重にもする前に考える

複数条件で、

90以上 → A
80以上 → B
それ以外 → C

のように分けるためIFを入れ子にできますが、条件が増えると式が読みにくくなります。

用途によってIFS、AND、OR、検索用の関数などを組み合わせる方が分かりやすい場合があります。

コピーすると参照セルが変わる

=IF(B2>=80,"合格","不合格")

を下へコピーすると、通常はB3、B4…へ変わります。

同じ基準値セルを固定したい場合は、

=IF(B2>=$F$1,"合格","不合格")

のように絶対参照を使います。

IFは「条件を満たしたら何を表示するか」を日本語で先に書き、それを式へ置き換えると作りやすくなります。
