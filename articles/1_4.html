Windows 11で画面録画する方法

Windows 11のSnipping ToolやXbox Game Barで画面を録画する手順と、Windows 10での方法、録画できないときの確認点を解説します。

結論

Windows 11では、画面の一部を録画するなら Snipping Tool（切り取りツール）、アプリやゲームの画面を録画するなら Xbox Game Bar が使えます。Windows 10ではSnipping Toolの録画機能が使えない場合があるため、まずXbox Game Barを試してください。

録画前に、マイク音声を入れるか、通知や個人情報が映らないかを確認しておきましょう。

Snipping Toolで画面の一部を録画する（Windows 11）

Snipping Toolの録画機能があるWindows 11では、録画したい範囲を四角く指定できます。

  1. スタートを開き、「Snipping Tool」または「切り取りツール」と入力して起動します。
  2. ツールバーの ビデオカメラのアイコンを選び、新規を押します。
  3. マウスで録画したい範囲をドラッグして指定します。
  4. スタートを押して録画を始めます。
  5. 終了するときは停止ボタンを押します。プレビューを確認し、保存ボタンから動画ファイルを保存します。

キーボードで Windowsキー＋Shift＋R を押して録画画面を開く方法もあります。アイコンが見当たらない場合は、Snipping ToolをMicrosoft Storeで更新できるか確認してください。Windowsの更新状態やアプリのバージョンによって、画面や使える機能が異なることがあります。

Xbox Game Barでアプリやゲームを録画する

Xbox Game Barは、ゲームやアプリの操作を録画するときに使えます。デスクトップ全体やエクスプローラーなど、一部の画面は録画対象にならないことがあります。

  1. 録画したいアプリやゲームを開きます。
  2. Windowsキー＋Gを押してXbox Game Barを表示します。
  3. キャプチャウィジェットの録画ボタンを押します。ウィジェットが見当たらない場合は、上部メニューから キャプチャを選びます。
  4. 録画を終えるときは、停止ボタンを押します。

ショートカットの Windowsキー＋Alt＋R で録画を開始・停止できます。マイクのオン・オフは Windowsキー＋Alt＋M で切り替えます。録画した動画は通常、ビデオ＞キャプチャフォルダーにMP4形式で保存されます。

Windows 10で録画する

Windows 10では、Xbox Game Barを使ってアプリやゲームを録画できます。録画したいアプリを開き、Windowsキー＋GでGame Barを表示して、キャプチャウィジェットから録画を開始します。ショートカットの Windowsキー＋Alt＋R も利用できます。

Windows 10のSnipping Toolには、画面録画のボタンが表示されないことがあります。その場合はXbox Game Barを使うか、必要な機能や利用条件を確認したうえで別の録画ソフトを選びます。

録画前に確認すること

録画にマイク音声を含めるか、アプリ内の音声も必要かを決めておきます。会議やブラウザーを録画する場合は、通知、メールアドレス、アカウント名などが映らないよう、不要な画面を閉じてください。

録画ファイルは容量が大きくなることがあります。保存先の空き容量を確認し、録画後は動画を再生して、必要な範囲と音声が記録できたか確かめましょう。他人の声や画面を録画・共有するときは、プライバシーや利用ルールにも配慮してください。

録画できないときの確認ポイント

録画ボタンが押せない場合は、録画対象のアプリを前面に表示してから、Game Barを開き直します。デスクトップや一部のウィンドウは対象外です。

Windowsキー＋Gで何も表示されない場合は、Windowsの設定でXbox Game Barが無効になっていないか確認します。設定画面で「Xbox Game Bar」を検索すると関連項目を探しやすくなります。

Snipping Toolに録画アイコンがない場合は、アプリの更新を確認します。更新しても使えない場合は、Windowsの版やアプリの提供状況による可能性があります。Xbox Game Barなど別の方法を試してください。

音声が入らない場合は、録画中のマイク設定と、Windowsのサウンド設定で選ばれている入力機器を確認します。マイクを使うときは、アプリにマイクへのアクセスが許可されているかも確認してください。

ワカルカモではこう使っています

短い操作手順を人に説明するときは、録画範囲を指定できるSnipping Toolを使い、アプリの操作を続けて撮りたいときはXbox Game Barを選ぶようにしています。録画後に一度再生し、通知やアカウント情報が映り込んでいないことも確認します。

まとめ

Windows 11で範囲を指定して録画するならSnipping Tool、アプリやゲームを録画するならXbox Game Barを使います。Windows 10ではXbox Game Barが基本的な選択肢です。録画対象や音声設定を確認し、保存した動画を再生して内容を確かめてください。
