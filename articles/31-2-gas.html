GASで複数のスプレッドシートを照合する方法

GASで複数のスプレッドシートを照合する方法について、初心者向けに具体的な手順・例・注意点を交えて解説します。

結論

複数のスプレッドシートを照合するときは、両方から比較キーを取得し、SetやMapにして差分を調べると効率的です。タイトルより記事IDなど一意な値を使うのがおすすめです。

例：管理表にあるのに投稿一覧にないIDを探す

function compareIds() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const master = ss.getSheetByName('管理表').getRange('A2:A').getValues().flat().filter(String);
  const posted = ss.getSheetByName('投稿済み').getRange('A2:A').getValues().flat().filter(String);

  const postedSet = new Set(posted.map(String));
  const missing = master.map(String).filter(id => !postedSet.has(id));

  console.log(missing);
}

別ファイル同士なら

SpreadsheetApp.openById('スプレッドシートID')で別のスプレッドシートを開けます。IDはURLの /d/ と /edit の間にある文字列です。

件数だけでなく中身を照合する

100件対100件でも、1件抜けて別の1件が余っていれば件数は一致します。ID単位で差分を見るほうが投稿漏れを発見しやすくなります。

まとめ

照合処理は、比較キーをそろえる→Set/Map化→差分だけ出すと、大量データでも確認対象を絞れます。
