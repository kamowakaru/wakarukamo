Windows 11で通知をオフにする方法

Windows 11で通知をアプリごと、またはまとめてオフにする方法と、作業中だけ通知を抑える応答不可の使い方を解説します。

結論

Windows 11の通知は、設定＞システム＞通知からアプリごと、またはまとめてオフにできます。作業中だけ通知音やバナーを抑えたい場合は、通知を恒久的に切るのではなく、応答不可を使う方法もあります。

特定のアプリだけ通知をオフにする

  1. Windowsキー＋Iを押して設定を開きます。
  2. システム＞通知を選びます。
  3. 「アプリやその他の送信者からの通知」の一覧から、変更したいアプリを選びます。
  4. アプリの通知をオフにします。

アプリの通知自体はオンにしたまま、バナー表示や通知音だけをオフにすることもできます。ロック画面に内容を表示したくない場合は、その項目だけを調整します。

すべての通知をオフにする

通知が一切不要な場合は、設定＞システム＞通知を開き、通知全体のスイッチをオフにします。重要なメールや予定の通知も表示されなくなるため、まずは不要なアプリだけオフにする方法がおすすめです。

作業中だけ通知を抑える「応答不可」

会議や集中したい時間だけ通知のバナーや音を抑えたいときは、応答不可を使います。通知を完全に削除する機能ではなく、応答不可の間に届いた通知は通知センターで確認できます。

手動で切り替えるときは、タスクバーの時計または通知ベルを選んで通知センターを開き、応答不可のベルアイコンを選びます。通知センターは Windowsキー＋N でも開けます。再び通知を受け取りたいときは、同じボタンを選んでオフにします。

曜日や時間帯、ゲーム中、全画面表示中などの条件で自動的に応答不可にする設定もあります。設定＞システム＞通知にある「応答不可を自動的にオンにする」を確認してください。

Windows 10で通知を調整する

Windows 10では、設定＞システム＞通知とアクションを開きます。アプリごとの通知をオフにするか、「アプリやその他の送信者から通知を取得する」をオフにして全体の通知を止められます。

作業中だけ通知を抑える場合は、アクションセンターの 集中モードを使います。Windows 10では、集中モードが「非通知モード」と表示されるバージョンもあります。Windows 11とは画面や名称が異なります。

通知が止まらないとき

Windows側の通知をオフにしても、アプリ内の通知やブラウザーのWebサイト通知は別に設定されている場合があります。特定のアプリやWebサイトからだけ通知が届く場合は、そのアプリやブラウザーの通知設定も確認します。

まとめ

特定のアプリだけ止めるなら、設定＞システム＞通知から対象アプリを選びます。すべて止める方法もありますが、会議や作業中だけなら応答不可が便利です。Windows 10では「通知とアクション」や「集中モード」から調整します。
